# detrend

多项式去趋势 + FIR 高通串联分析：阶数–残留关系、与高通截止的耦合项、串联底噪、两档截止耗时。

`make test` 跑模块自检；`make run` 跑实验（64 次噪声实现平均），表格打印到 stdout，CSV 写入 `../artifacts/detrend_*.csv`。

## 实验设置

- fs = 49152 Hz，段长 N = 16384；能量评估取中段 K = 8192 加 Hann 窗（避开边界瞬态）
- 信号 x = t + w：趋势 t(x) = 20·(x³ − 0.5x² + 0.25x − 0.1) + 3·sin(π(x+1))（3 次多项式 + 非多项式慢漂），w 为 σ²=1 高斯白噪声
- 低频评估带 B = [0, 240 Hz)，恰为 40 个单边 bin（带内噪声自由度 D_B = 80）
- 高通：Hamming 窗 sinc 谱反演 FIR，过渡带 = max(0.5·fc, 15 Hz)，零相位应用
- 去趋势：离散 Legendre 正交基投影（三项递推 + 两遍 MGS），数值稳定到任意实用阶数

## 推导

### 1. 阶数 p 与残留低频能量

设 P_p 为到 ≤p 阶多项式子空间（维 p+1）的正交投影，残差 r = (I − P_p)x。分解：

- **趋势部分**：t 为 d 次多项式时，p ≥ d 则 (I−P_p)t = 0；非多项式漂移的残留随 p 按其在多项式基上的展开衰减（正弦半波：偶阶项系数为 0，故 p=3→4 不降、4→5 骤降）。
- **噪声部分**：E‖r_w‖² = (N−p−1)σ²。被投掉的 p+1 个 Legendre 维度的谱集中在 f ≲ p·fs/N（约 20 Hz 内），故带内噪声残留近似

  E_LF(p) ≈ ‖(I−P_p)t‖²_B + σ²·(2F_B/fs)·(1 − (p+1)/D_B)

  即每阶约再吃掉带内噪声的 1/D_B。注意该闭式是**上限**：加窗估计的主瓣（Hann ≈ 24 Hz）比投影刻出的凹口（≲20 Hz）宽，泄漏会回填一部分（见第 3 节）。

### 2. 与高通截止的耦合项

设 G_fc(f) = |H_fc(f)|²。串联后带内残留

E(p, fc) = ∫_B S_p(f)·G_fc(f) df = E_d(p)·Ḡ_fc + |B|·cov_B(S_p, G_fc)

其中 E_d(p) 是去趋势残留、Ḡ_fc 是带内平均功率增益。**耦合项即第二项：去趋势残留谱形与高通功率响应在带内的协方差**。可分离估计 E_sep = E_d(p)·Ḡ_fc 只在残留谱平坦（纯噪声）时成立。去趋势残留集中在最低几个 bin——正是高通衰减最深处——故 cov < 0，串联实测显著低于可分离估计（C 为负）。p 足够大、残留只剩白噪声时 S_p 平坦，C → 0。

定义 C(p,fc) = 10·log10(E_meas / E_sep)，实测见 `detrend_coupling.csv` 与 `../artifacts/detrend_coupling.html`。

### 3. 串联底噪

朴素自由度模型预言串联底噪 = 单模块 × (1 − (p+1)/D_B)（p=5 时 −0.34 dB）。实测 ≈ 0 dB（fc ≥ 20 Hz）。机制：去趋势刻出的谱凹口（≲20 Hz）与高通过渡带**重叠**——该区域能量已被高通压制，去趋势的扣除无从叠加。两者在同一频段做同一件事，效果不独立，这就是底噪上的耦合。验证：fc = 5 Hz（高通放过凹口区）时串联底噪确实低于单模块（−0.031 dB）；子带诊断显示被投掉的能量集中在 bin 1–4（6–24 Hz 子带：1.038e-3 → 8.15e-4，−1.05 dB），全带仅 −0.17 dB（主瓣糊化稀释）。

### 两档截止耗时（去趋势 p=5 + FIR，N=16384，WSL2）

| fc | 抽头数 | 单次耗时 |
|---|---|---|
| 40 Hz | 8111 | ≈ 51 ms |
| 240 Hz | 1351 | ≈ 9.4 ms |

耗时 ∝ 抽头数 ∝ 1/过渡带：截止越低过渡带越窄，40 Hz 档约为 240 Hz 档的 5.4–6.6×。截止选择直接是算力决策。

## 选型结论

规则：(1) 可行集 = {E_串联(p,fc) ≤ 1.5 × 串联底噪(fc)}；(2) 在可行集内取最小 fc（低频信息损失最小）；(3) 并列取较低阶、较低算力。

- **p\* = 5**：首个把非多项式漂移也压进噪声底的阶数（p=3/4 残留 3.1e-2 > 1.5×平台 9.9e-3）。
- **fc\* = 5 Hz**：p=5 时趋势残留 1.1e-4 已没入噪声，任意截止可行，取最小档。
- 耦合项的实用价值：p=3 时可分离设计会要求 fc ≥ 160 Hz（E_sep(20 Hz) = 2.8e-2 超标），但耦合修正 −4.9 dB 后 fc = 10–20 Hz 即达标——**忽略耦合会把截止定高 8–16 倍**，白白切掉 20–160 Hz 内容。
- 成本权衡：若允许牺牲 ≤240 Hz 内容，(p=3, fc=240 Hz) 也可行且 FIR 耗时降到 1/5；按"最小低频损失"准则仍取 (5, 5 Hz)。
