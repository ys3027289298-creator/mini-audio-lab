# tfres

时频分辨率：下界推导、窗型偏离、三候选窗长选点。`make test` 跑自检并复现本文全部数值。

## 1. 下界推导（Gabor/Heisenberg）

设窗 $w(t)$，$\|w\|_2=1$，时频均值为 0（平移不改变宽度）。定义 RMS 宽度：

$$\Delta t^2=\int t^2|w|^2dt,\qquad \Delta\omega^2=\frac{1}{2\pi}\int\omega^2|W(\omega)|^2d\omega=\int|w'(t)|^2dt$$

（第二步用 Parseval 与微分性质 $\mathcal{F}\{w'\}=i\omega W$。）由分部积分，且 $|w|^2$ 在无穷远消失：

$$1=\int|w|^2dt=-\int t\frac{d}{dt}|w|^2dt=-2\,\mathrm{Re}\int t\,w^*w'\,dt\le 2\Delta t\,\Delta\omega$$

末步为 Cauchy–Schwarz。故

$$\boxed{\ \Delta t\,\Delta\omega\ge\tfrac12\ \}\iff \Delta t\,\Delta f\ge\frac{1}{4\pi}\approx 0.07958\ \text{s·Hz}$$

等号当且仅当 $w'=\lambda t w$，即**高斯窗**。矩形/海明窗在边缘有跳变，$w'$ 含冲激，$\int|w'|^2$ 发散——RMS 带宽无界，实测 $\Delta t\Delta\omega\sim|\text{跳变}|\sqrt{L}$。

## 2. 窗型对下界的偏离（实测，L=4096）

| 窗 | Δt/T | Δω·T | Δt·Δω | 相对下界 0.5 | 渐近行为 |
|---|---|---|---|---|---|
| gauss (σ=0.12T) | 0.0849 | 5.893 | 0.5000 | 1.000 | 达界 |
| hann | 0.1414 | 3.628 | 0.5131 | 1.026 | 收敛，+2.6% |
| hamming | 0.1529 | 13.91 | 2.126 | 4.25 | 发散 ∝0.08√L（边缘跳变 0.08） |
| rect | 0.2887 | 106.6 | 30.76 | 61.5 | 发散 ∝√L（跳变 1），L=1024/4096/16384 实测 15.38/30.76/61.53 |

结论：RMS 意义下只有两端归零的窗（hann、高斯）有有限乘积；hann 离下界仅 2.6%，实际选型用它。

## 3. 三候选窗长评估（fs=48 kHz，hann，双音 2000/2120 Hz，间距 120 Hz）

| N | Δt_rms (ms) | Δf_rms (Hz) | Δt·Δf (s·Hz) | ENBW Δf (Hz) | 双音谷深 (dB) |
|---|---|---|---|---|---|
| 256 | 0.75 | 108.3 | 0.08167 | 281.2 | 0.00（糊：双峰合并） |
| **1024** | **3.02** | **27.1** | **0.08167** | **70.3** | **8.33（可分辨）** |
| 4096 | 12.07 | 6.8 | 0.08167 | 17.6 | 63.18（拖：时域涂抹 4×） |

三点频谱对照（`make test` 输出 ASCII 图）：N=256 两峰并成单包络；N=1024 双峰间出现 8.3 dB 谷；N=4096 谷深 63 dB 但瞬态涂抹 12 ms。

注意 Δt·Δf=0.08167 对三个 N 完全相同（=hann 乘积 0.5131/2π，距下界 0.07958 仅 2.6%）——**窗长不改善乘积，只在 Δt 与 Δf 之间重新分配预算**，“拖”与“糊”只能权衡不能兼得。

## 4. 选点依据

选 **N=1024**。规则：满足频率分辨约束的最小窗长——ENBW Δf = 1.5·fs/N ≤ 0.6×音距（72 Hz）⇒ N ≥ 1000，取 1024。

- N=256：ENBW Δf 281 Hz > 120 Hz 音距，双峰合并（谷深 0 dB），频率上糊，否决；
- N=4096：频率分辨富余 4 倍用不上，Δt_rms 从 3.0 ms 涨到 12.1 ms，瞬态拖尾 4 倍，否决；
- N=1024：刚好以 0.6 倍余量解开 120 Hz 音距（谷深 8.3 dB），同时把时域涂抹压到 3 ms 级。
