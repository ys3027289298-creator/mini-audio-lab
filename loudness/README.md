# loudness

短时响度统计，对背景噪声稳健。`make test` 跑自检。

模型 `x = a·s + n`：语音活动占比 p，噪声方差 σ²_n。窗长 T、带宽 B 时窗能量为
χ²(2BT)，静音簇响度散布 σ_L = 4.34/√(BT) dB；边界混合窗占比 w(T) ∝ T，故静音
对话语侧分位数的污染随窗变短单调下降，下限为簇可分辨条件
T_min = (3·4.34/Δ)²/B，Δ = 10·log10(1 + σ²_s/σ²_n)。分位数反解 q* = 1 − p̂/2。

自检合成同一说话人在安静（−60 dBFS）与嘈杂（−30 dBFS）房间的两段素材，
输出全段平均、分布中位数、反解分位数三组值及窗长扫描；若两房间代表值偏离
超过 1 dB，则列出被当成静音的说话间隙占比对照。
