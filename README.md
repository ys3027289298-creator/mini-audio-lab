# mini-audio-lab

游戏音频基础模块，C 实现，每目录独立构建可自测。

| 目录 | 内容 |
|---|---|
| `stream/` | 统一输出长度推导（单一事实来源，纯头文件） |
| `resampler/` | 线性重采样、输出长度推导、流式变体 |
| `mixer/` | 增益斜坡混音、削波检测、跨块连续斜坡的流式变体 |
| `spatial/` | 等功率声像、距离衰减、奇数帧跨块携带的流式变体 |
| `pipeline/` | 双模式（`MA_UNIFY=0/1`）流式演示与翻倍采样率耗时基准 |
| `tools/` | 独立 Python 字节级校验、长度表、咔哒计数、频谱图 |
| `artifacts/` | 再生的交付材料（`tools/regen.sh` 一键生成） |

## 统一长度推导

旧路径里三个环节各自按块取整：重采样每块 `floor(B/r)` 丢掉余数样本，
mixer 每块重启增益斜坡，spatial 对奇数长度块 `ceil(n/2)` 凭空多出一个
立体声帧并让后续块整体错位——每 2 秒块边界因此产生一次咔哒。

统一后所有长度来自 `stream/stream.h`：

- 重采样总长 `floor(N/r)`，分块用相邻前缀 `floor` 之差，余数不再丢失；
- mixer 长度不变，斜坡改为整条流连续；
- spatial 用 `floor(M/2)`，奇数帧携带到下一块与首帧配对，不造帧。

`tools/regen.sh` 从零构建并产出：各环节频谱图、长度对照表、
采样率翻倍耗时，以及独立 Python（`python3 -I`）逐字节重算校验。
