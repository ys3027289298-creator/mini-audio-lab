# phasecheck

同一素材叠两遍却更轻时，判定这是不是相位抵消，并给出电平、相干系数、
抵消区间和检测开销。C 实现，无依赖，`make test` 跑自检。

## 什么时候会需要它

两轨"同一素材"叠在一起（双轨叠加、重复播放、L/R 合并、备份轨叠加），
听感反而变薄、变轻，或者电平比只留一轨还低。原因通常有两个，处理方式
完全不同：

1. **极性/相位反相**——两轨对应频段真正相减，叠加后该频段被削掉。
2. **时延/梳状滤波**——两轨错位几百个样本，某些频段相消、某些频段相长。

本工具把两种情况分开报，而不是笼统说"有抵消"。

## 核心关系：相干性就是电平变化

对某一频段、某一时间窗，两轨的互谱为 `C = Σ_f Σ_k Xa[k,f]·conj(Xb[k,f])`，
各自功率为 `P_a`、`P_b`。定义**带符号相干** `rho`：

```
rho = Re(C) / sqrt(P_a·P_b)          -1 ≤ rho ≤ 1
```

叠加后的信号功率是

```
P_sum = P_a + P_b + 2·Re(C)
```

以"两路互不相关、按功率相加"为基准（`P_a + P_b`），增益为

```
G = P_sum / (P_a + P_b) = 1 + rho
dL = 10·log10(1 + rho)   dB
```

| rho | 含义 | 相对功率和的电平 |
|---|---|---|
| +1 | 两轨完全相同 | +3.01 dB |
| 0 | 互不相关 | 0 dB |
| −0.2 | 轻度反相 | −0.97 dB |
| −1 | 完全反相 | −∞（报告以 −60 dB 封底） |

所以"叠两遍反而更轻"在数学上就是 **rho < 0**；`dL` 直接量化轻了多少。
推导假设带内两轨功率相近，报告同时打印每带两轨功率，方便核对这个前提。

## 判定阈值与误报率

对每带每窗，独立复样本数 `nu = B·W`（`B` 为该带频点数，`W` 为聚合帧数）。
零假设（两轨在该带独立）下，幅度平方相干服从

```
gam² ~ Beta(1, nu−1)，且 |rho| ≤ gam
P(rho ≤ −t) ≤ P(gam ≥ t) = (1 − t²)^(nu−1)
```

取 `alpha_band = alpha / n_active`（跨频段 Bonferroni），解出阈值

```
t_band = sqrt(1 − alpha_band^(1/(nu−1)))
```

`rho_band < −t_band` 即判该带该窗为抵消。`alpha` 是**单窗、跨全带**的族系
误报率，报告会打印期望误报窗数 `nwin·alpha`。

**关键：检测粒度是"多帧聚合"，不是单帧。** 单帧相干的 `nu=1`，分布退化、
幅值恒为 1，任何逐帧阈值都会给出约 30% 的误报。本工具以 `W` 帧聚合后
才检验，`nu ≥ 2` 是硬性前提（`--selftest` 有断言）。

### 实测误报率（`./phasecheck --calib 200`）

噪声型素材，200 组独立样本对，48 kHz，2 s，1 kHz 分帧：

| 素材 | W | alpha | 名义单带率 | 实测单带率 | 比率 | 名义单窗率 | 实测单窗率 |
|---|---|---|---|---|---|---|---|
| noise | 32 | 0.01 | 0.00125 | 0.00031 | 0.25 | 0.01 | 0.0025 |
| noise | 32 | 0.05 | 0.00625 | 0.00047 | 0.08 | 0.05 | 0.0038 |
| noise | 32 | 0.10 | 0.0125 | 0.00234 | 0.19 | 0.10 | 0.0188 |
| tonal | 32 | 0.01 | 0.00125 | 0.410 | **328×** | 0.01 | 0.239 |
| tonal | 32 | 0.05 | 0.00625 | 0.420 | **67×** | 0.05 | 0.239 |
| tonal | 32 | 0.10 | 0.0125 | 0.425 | **34×** | 0.10 | 0.239 |

- **噪声型素材**：实测误报显著低于名义值。Beta 界在"一带多频点聚合"下是
  保守的，可以直接用。
- **平稳纯音素材**：实测误报是名义值的 30–330 倍，单窗次误报率可达 24%。
  原因是纯音跨帧保持相位，`nu_eff` 远小于 `B·W`，独立性假设不成立。

**结论**：`alpha` 只在噪声型/瞬态丰富的素材上成立。对持续纯音（合成器
长音、测试音、持续弦乐）不要相信名义误报率，应改看 `rho_total` 的量级，
或把 `--win` 调大、把判定建立在多窗持续性上。报告始终打印 `rho_total`
和逐窗区间，正是为了让这种情况可以被人工复核。

### 检出功效（`--calib` 同时输出）

在 500 Hz / 1 kHz / 4 kHz 带内注入已知 `rho`，400 次试验，W=32，alpha=0.01：

| rho_true | 500 Hz | 1 kHz | 4 kHz |
|---|---|---|---|
| −0.1 | 0.87 | 0.88 | 0.94 |
| −0.2 | 0.90 | 0.94 | 1.00 |
| −0.3 | 0.94 | 0.99 | 1.00 |
| −0.5 | 0.99 | 1.00 | 1.00 |
| −0.9 | 1.00 | 1.00 | 1.00 |

高频带频点多、`nu` 大，同样的 `rho` 更容易检出。|rho| ≥ 0.3 基本必检，
|rho| ≈ 0.1 是分辨率边缘。比这更小的抵消在统计上无法与噪声区分，报告
不会声称检出。

## 用法

```sh
make                      # 构建
make test                 # 自检（含误报率检查）
./phasecheck A.wav B.wav          # 只分析，打印完整报告
./phasecheck A.wav B.wav --out mix.wav   # 检测到抵消时拒绝写，见下
./phasecheck A.wav B.wav --accept-cancellation --out mix.wav  # 知情下强制写
./phasecheck --calib 200          # 实测误报率与功效曲线
./phasecheck --bench 2,8          # 两档声源数的检测耗时
./phasecheck --selftest
```

输入要求：16-bit PCM WAV；立体声文件默认取 0 号声道，可追加两个位置参数
指定声道号。**声道是选取、不混音**——混声道本身可能造成抵消，会污染测量。

## 输出报告

| 段 | 内容 |
|---|---|
| 头 | 采样率、使用样本数、被丢弃的尾部样本、帧长、窗长、窗移、`alpha`、期望误报窗数 |
| `[levels-before-and-after]` | 两轨 RMS/峰值、叠加后 RMS/峰值、相对单轨的实际电平变化、两轨互不相关时预期的电平变化、二者之差（shortfall，负值即抵消）、叠加是否静音 |
| `[cross-correlation]` | 零时延相关系数、峰值相关系数、最佳时延（样本/毫秒）、搜索范围 |
| `[cross-correlation-lags]` | 逐时延相关系数表 |
| `[coherence-by-band]` | 每八度带的频点数、`nu`、阈值、窗数、标记数、标记比例、整段 `rho_total`、整段增益 |
| `[cancel-intervals]` | 每带逐区间：起止时间、窗号、平均 `rho`、最差增益 |
| `[cancel-intervals-any-band]` | 任一带被标记的时间跨度合并（含涉及哪些带） |
| `[alignment-recheck]` | 若检到非零时延且有标记：按最佳时延对齐 B 后重跑，报告对齐前后标记数，区分"时延造成"与"真实反相" |

## 检测到抵消时绝不静默处理

- 报告最后一行 `CANCEL_DETECTED=1`；同时向 stderr 打印醒目告警。
- `--out` 在检测到抵消时**拒绝写文件**（`mix_written=0`，
  `mix_refused_reason=cancellation_detected`），除非显式给了
  `--accept-cancellation`。强制写出时会打印 `mix_written=1` 和削波样本数。
- 退出码：`0` 无抵消；`3` 检测到抵消；`4` 检测到抵消且拒绝了写出请求；
  `1` 输入错误；`2` 参数错误。便于脚本 `set -e` 或 `if` 分支。

## 时延 vs 反相的区分

纯时延会让低频带呈负相干（梳状滤波），但全带 `rho` 不偏负，且
`peak_corr` 接近 1、`best_lag` 非零。对齐复核会把这些标记按最佳时延
位移 B 后重算：

- 标记消失（`delay_explains_cancellation=1`）→ 根因是时延，应做延迟对齐，
  不是极性翻转。
- 标记仍在（`genuine_inversion_after_align=1`）→ 对齐后依然反相，根因是
  极性/相位，应检查录制或处理链的极性。

实测例（1 kHz 仅最后 2 s 反相 + B 整体延迟 6 ms，`--max-lag 1024`）：
`best_lag=288`（6.000 ms），标记窗 35 → 对齐后 5，判为"时延不能完全解释，
仍有真实反相"，与素材真相一致。

## 检测耗时

耗时只取决于时长与 FFT 点数，与声源数无关（声源数只影响素材合成）：

```
source_count=1   10 s, 48 kHz, 480k samples   analysis 18.9–20.1 ms   ~500–570× 实时
source_count=2   ...                           analysis 20.8 ms        ~482× 实时
source_count=8   ...                           analysis 17.5 ms        ~570× 实时
source_count=16  ...                           analysis 17.1 ms        ~585× 实时
```

（`--bench N1,N2` 复现；两次运行间 ±10% 抖动来自调度，量级稳定。
`source_count` 只影响素材合成耗时 `synth_ms`，不影响 `analysis_ms`。）

## 局限

- 只用单声道；立体声请分别对每个声道跑一次或先确认声道内容。
- 只读 16-bit PCM WAV，不支持 24-bit、浮点或 `WAVE_FORMAT_EXTENSIBLE`。
- 尾部不足一帧的样本被丢弃，报告用 `tail_samples_dropped` 给出具体数量。
- 假设带内两轨功率相近。若两轨电平差很多，`rho` 的分母会被较强一轨主导，
  抵消量会被低估；报告输出每带 `P_a`/`P_b` 供核对。
- 平稳纯音下名义误报率不成立（见上），需人工看 `rho_total` 与区间持续性。
- 只有 `|rho| ≥ 约 0.1`（取决于频带与 `nu`）的抵消可被检出；更小的量级
  与噪声不可分。
