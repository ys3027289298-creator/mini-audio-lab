# footsteps

五种材质（草地 / 沙地 / 木头 / 石板 / 金属）的脚步音效：由硬度 H 与孔隙率 φ
**算出**接触共振 f0 与衰减时间 T60，再据此合成脉冲、实测频谱质心和衰减时长。

```
make test      # 自检：映射方向、逐样本 T60 误差、50/50 分类、2σ 椭圆不相交
make samples   # 生成 samples/<材质>_<00..09>.wav 与 samples/samples.csv
python3 tools/plot_stats.py   # samples/materials_scatter.png

`samples/` 和编译产物已在 `footsteps/.gitignore` 中忽略，可随时重建。
```

## 映射（不是手调参数）

硬度按归一化对数刚度定义：H=0 对应 E=1e6 Pa（软有机质），H=1 对应 E=1e11 Pa（钢），
即 E(H) = E_LO · (E_HI/E_LO)^H。孔隙率 φ 是接触面中空气所占体积分数。

```
E_eff   = E(H) · (1 - φ)²                       孔隙让有效承载截面变小
E*      = E_eff / (1 - ν²)                      接触模量，ν = 0.30
a       = (3·F·R / (4·E*))^(1/3)                Hertz 接触半径，F = 800 N，R = 0.03 m
f0      = sqrt(2·a·E* / m) / 2π                 m = 0.35 kg 有效模态质量
η       = η_min + (η_max - η_min)·(1 - H)² + κ·φ
T60     = ln(1000) / (π·f0·η)
```

η_min = 5e-4（金属结构阻尼），η_max = 0.25（完全软接触），κ = 0.35（每单位空气
分数的附加损耗）。T60 来自单自由度阻尼振子 e^(−πηf0·t) 衰减 60 dB。

| 材质 | H | φ | f0 (Hz) | η | T60 预测 (ms) |
|---|---|---|---|---|---|
| 草地 | 0.22 | 0.55 | 87 | 0.345 | 73 |
| 沙地 | 0.32 | 0.40 | 154 | 0.256 | 56 |
| 木头 | 0.77 | 0.06 | 1171 | 0.035 | 54 |
| 石板 | 0.90 | 0.01 | 1996 | 0.0065 | 170 |
| 金属 | 1.00 | 0.00 | 2950 | 0.0005 | 1491 |

H 和 φ 是读入的两个数，其余全部由公式给出；换材质只改这两个数。

## 合成与测量

每个样本：三个圆板模态 1 : 2.756 : 5.404（同一 T60），孔隙材质另加 0.5·f0–6·f0
的带限噪声床（频域整形，不用离散分音——分音之间的拍频会污染能量衰减斜率），
外加 2 ms 接触咔哒声。每样本对载荷、f0、η 加小幅扰动后确定性随机（splitmix64，
同 seed 同波形）。

- **频谱质心**：46 ms Hann 窗、4× 零填充 FFT，按帧能量加权，仅计 > 50 Hz 的帧，
  低于最响帧 −60 dB 的帧跳过。
- **T60**：Schroeder 反向能量积分，取 −5 ~ −25 dB 区间的线性拟合斜率。

## 五组数据（10 样本，实测）

| 材质 | 质心 (Hz) | T60 (ms) | 到最近一组 |
|---|---|---|---|
| 草地 | 189 ± 33 | 81 ± 12 | 沙地 3.9σ |
| 沙地 | 352 ± 49 | 58 ± 7 | 草地 3.9σ |
| 木头 | 2602 ± 210 | 56 ± 3 | 草地 20.2σ |
| 石板 | 4539 ± 572 | 170 ± 8 | 木头 29.7σ |
| 金属 | 6177 ± 460 | 1434 ± 65 | 石板 51.2σ |

（均值 ± 样本标准差。“到最近一组”是二维对数空间中两组均值的马氏距离，用合并
协方差，单位 σ。）

散点图见 `samples/materials_scatter.png`。以 2σ 椭圆判定，五组两两不相交；
只有草地与沙地靠得最近，要到约 3σ 才接上。

两点读数说明：质心是三个模态加噪声床的能量加权平均，约为 f0 的 2.2 倍
（模态比 1 : 2.756 : 5.404 把均值抬上去），所以质心不能直接和 f0 对号
入座，比较要用同一套测量。表中的实测均值与上面“T60 预测”列不完全相等，
差值来自每样本对载荷/f0/η 的随机扰动（草地有样本抽到重尾的低载荷，
T60 被拉长）；逐样本的预测值列在 `samples/samples.csv` 的 `pred_t60_ms`，
实测与逐样本预测的偏差在 ±15% 以内（自检 `t60_matches_mapping`）。

## 为什么草地和沙地接近

两者的硬度都低（0.22 / 0.32），接触都很软、损耗都大，f0 只差 1.8 倍，T60
只差 1.4 倍——在二维平面上是相邻的两团。它们能分开靠的是 φ 的作用：
草地的 φ=0.55 比沙地 0.40 更大，一方面让 f0 更低，另一方面让 η 更高，
于是质心更低、衰减更长。但这个差距只有约 3.9σ，且两个维度各自都有
10% 以上的离散度（载荷与相位的随机扰动），所以是最先接触的一对。
换句话说：草地与沙地在物理上本来就只差“孔隙多一点、更软一点”，
不是两种完全不同的激励机制——这是接近的根因，而不是参数没调开。
