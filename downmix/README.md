# downmix

5.1（L R C LFE Ls Rs）→ 双声道（Lt Rt）能量守恒下混，修复下混后低频被抵消的问题。

- `make test`：C 自检（权重表、低频能量、解析对照、旁路逐字节校验、反相 LFE 缺陷复现）
- `python3 -I tools/crosscheck.py`：独立 Python（仅标准库）复算同一份 C 落盘样本

## 1. 缺陷是怎么产生的

朴素下混把多个声道直接相加。两个独立错误：

1. **能量不守恒**：每个声道以权重 1 同时进 Lt 和 Rt，输出能量随声道数线性增长，6 声道全电平信号每路输出能量达单声道的 3 倍，必然削波。
2. **低频抵消**：LFE 若以相反极性送入左右声道（`wL = -wR`），双声道本身的能量没有任何异常，但任何下游单声道折叠
   `m = (Lt + Rt)/√2` 都会让 LFE 贡献 `(wL + wR)/√2 · x_lfe = 0`，低频整体消失。只看双声道电平时该缺陷完全不可见。

## 2. 下混矩阵推导

记输入 `x ∈ ℝ⁶`，输出 `y = Mx`，`M ∈ ℝ²ˣ⁶`，第 j 列 `m_j = (wL_j, wR_j)ᵀ`。

### 2.1 能量守恒条件

声道互不相关假设下（与 `spatial/` 等功率声像同一前提），`E[xxᵀ] = diag(σ₁²…σ₆²)`：

```
E[‖y‖²] = tr(M E[xxᵀ] Mᵀ) = Σ_j σ_j² · ‖m_j‖²
```

要让每个声道独立保持能量，充要条件是**每列范数平方为 1**：

```
wL_j² + wR_j² = 1,  ∀j
```

相关信号不满足该前提时，瞬时能量可有建设性/抵消性干涉——这是一切线性下混的固有性质，列范数准则是标准设计目标（机器精度下的恒等式验证见第 5 节）。

### 2.2 各声道权重

取极坐标 `(wL, wR) = (cos θ, sin θ)`，自动满足范数为 1。

| 声道 | 设计依据 | wL | wR | wL²+wR² |
|---|---|---|---|---|
| L | 直达，保持原像位 | 1 | 0 | 1 |
| R | 直达 | 0 | 1 | 1 |
| C | 幻像中央，等功率 θ=45° | 1/√2 ≈ 0.70710678 | 1/√2 ≈ 0.70710678 | 1 |
| LFE | 同相送入，θ=45°，**同号** | 1/√2 ≈ 0.70710678 | 1/√2 ≈ 0.70710678 | 1 |
| Ls | 等功率声像，θ=30° | cos30° ≈ 0.86602540 | sin30° = 0.5 | 1 |
| Rs | 镜像声像，θ=60° | 0.5 | 0.86602540 | 1 |

即

```
Lt = L + (C + LFE)/√2 + (√3/2)·Ls + (1/2)·Rs
Rt = R + (C + LFE)/√2 + (1/2)·Ls + (√3/2)·Rs
```

### 2.3 为什么 LFE 必须同相

单声道折叠中第 j 声道的增益为 `g_j = (wL_j + wR_j)/√2`：

- 同相 45°：`g = (1/√2 + 1/√2)/√2 = 1`，低频全保留；
- 反相（wR = −wL）：`g = 0`，低频精确抵消。

自检同时构造了反相 LFE 的错误矩阵作为对照：它的双声道低频能量完全正常，只有单声道折叠能量归零——证明"看双声道电平"无法发现该 bug。

环绕取 30°/60° 而非 45°，是让左右环绕保持可分辨的横向像位；任何满足列范数为 1 的角度都是合法设计，本模块把角度集中在常量表里，替换不影响守恒证明。

## 3. 低频能量对照（自检实测）

测试信号：6 个声道各放一个不同 DFT 整数频点的余弦（声道间严格正交），仅 LFE（频点 2，幅度 0.8）落在低频段（bin 0–4）。能量按 Parseval 用 FFT 在频域统计，`E = Σ|X[k]|²/N`。

C（float32）实测，理论 LFE 能量 `N/2·0.8² = 81.92`：

| 路径 | 低频能量 |
|---|---|
| 输入 LFE | 81.919929 |
| 正确矩阵，双声道 Lt+Rt 之和 | 81.919908 |
| 正确矩阵，单声道折叠 | 81.919905 |
| 反相 LFE 错误矩阵，双声道之和 | 81.919934（看不出问题） |
| 反相 LFE 错误矩阵，单声道折叠 | **0.000000（抵消）** |

总能量（时域，6 声道全部）：输入 241.920003，输出 241.919928，相对误差 3.1e-7。

Python 用 float64 在理想信号上复算同一组恒等式：总能量相对误差 **2.35e-16**，低频能量精确到 81.92，反相矩阵单声道折叠残余 2.8e-27。float32 路径的 ~1e-7 偏差经同一脚本定位为输入量化（`cosf` 近似 + float32 舍入破坏频点正交性），与矩阵无关。

## 4. 与逐声道解析计算的差

`analytic_downmix()` 不用矩阵循环，而是按第 2.2 节公式逐声道显式展开、double 精度独立计算：

```
max |矩阵路径(float32) − 解析路径(float64)| = 1.684e-07
两路输出总能量相对差 < 1e-5
```

`tools/crosscheck.py` 再用第三种实现（纯 Python 标准库、直接 DFT）对 C 落盘的原始 float32 帧复算，样本级最大差同为 1.684e-7，三条实现路径互相印证。

## 5. 关闭下混：逐字节相同

`dm_init(&ctx, 0)` 进入旁路：6 进 6 出，`dm_process` 对每个声道走 `memcpy`，不做任何浮点运算。自检用两组独立证据确认：

1. 进程内 `memcmp` 整块内存：`bypass_byte_identical=1`；
2. 输入/输出各落盘一个原始 float32 文件，Makefile 用 `cmp` 比较：`bypass_cmp=identical`，Python 侧再比一次字节流。

## 6. 设计边界

- 守恒的是二阶能量，不是峰值：多声道同相瞬态仍可能超过满刻度，输出端应接 `limiter/`。
- 列范数准则依赖声道互不相关；强相关素材（如多声道同播同一信号）的瞬时能量由相关系数决定，任何线性矩阵都无法对任意相关矩阵同时守恒。
- LFE 按低频带限声道处理；矩阵不做分频管理，频带划分责任在上游。
