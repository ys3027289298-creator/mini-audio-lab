# meter

帧功率平均器的"方差—延迟"交换关系实验台。`make test` 跑自检，`make bench` 跑三点实测。

## 交换关系式

设帧长 `Tf = FRAME/fs`（默认 256 @ 48 kHz = 5.3333 ms），取最近 `N` 帧的功率平均。
白噪声下相邻帧功率独立，dB 域输出标准差为

```
sigma_dB(N) = (10/ln10) * sqrt(2 / (FRAME*N)) = (10/ln10) * sqrt(2*Tf / T)
```

其中 `T = N*Tf` 是平均窗长。用平均年龄 `age = N*Tf/2`（冲激响应质心再平均半帧采样相位）可以把上式写成与 N 无关的常数形式：

```
sigma_dB^2 * age_ms = (10/ln10)^2 / fs = 0.39294 dB^2*ms      (白噪声, 盒式平均)
```

`age` 线性增长而 `sigma^2` 线性下降，乘积恒定 —— 这就是"越准越迟钝"的定量形式：延迟翻倍只能换到 sqrt(2)=1.41 倍的方差下降。实测三点（下表 `sigma2_age` 列）为 0.394 / 0.391 / 0.402，与常数 0.393 在 2% 内一致。

一般窗的版本（任何窗长 T 的估计器下界）：

```
sigma_dB >= sqrt(2*(10/ln10)^2/(fs*T_ms)) = 0.8865 / sqrt(T_ms)
```

## 三点实测（48 kHz，帧长 256，白噪声，600 s，4 seed）

| N | 窗长 ms | t10 ms | t90 ms | tsettle ms | age ms | sigma dB (95% CI) | 理论 dB | sigma²·age |
|---|---|---|---|---|---|---|---|---|
| 1 | 5.3 | 5.3 | 5.3 | 5.3 | 2.67 | 0.3844 (0.3823–0.3865) | 0.3839 | 0.394 |
| 8 | 42.7 | 5.3 | 42.7 | 42.7 | 21.33 | 0.1354 (0.1347–0.1361) | 0.1357 | 0.391 |
| 64 | 341.3 | 32.0 | 309.3 | 304.0 | 170.67 | 0.0485 (0.0469–0.0502) | 0.0480 | 0.402 |

规格取 tsettle <= 50 ms 且 sigma <= 0.15 dB：

- **N=1 不可行（方差失效）**：sigma 0.3844 dB 已贴着 5.33 ms 窗的信息下界 0.3839 dB（差 0.13%）；要 0.15 dB 至少需要 34.9 ms 窗。这不是"没调好"，是单帧观测的物理极限。
- **N=8 可行**：42.7 ms 建立、0.135 dB。
- **N=64 不可行（延迟失效）**：均值年龄 170.7 ms、群延迟 168.0 ms 已远超 50 ms 预算，且 sigma 0.0485 dB 对应的信息下界要求 333.8 ms 窗，自相矛盾。

解析可行带为 `N ∈ [7, 10]`；`./meter sweep 4 6 7 9 10 11` 实测边界为 N=6 方差超标（0.157 dB）、N=7 起达标、N=10 建立 48.0 ms 达标、N=11 建立 53.3 ms 超标。

## 延迟的测法

1. **tsettle（判可行性用）**：功率域阶跃。常数幅度正弦（每帧恰好 5 个整周期，避免帧内相干抵消），幅度 0.05→0.4（功率 +18 dB），逐帧过表；取输出首次进入终值 0.5 dB 以内的帧号乘 `Tf`。盒式平均的闭式解是 `ceil(0.8902*N)` 帧，自检逐点核对。
2. **群延迟（波形延迟）**：盒式冲激响应的质心，`(N-1)/2` 帧。自检核对 0、3.5、31.5 帧。
3. **均值年龄（交换关系用）**：`age = gd + Tf/2`，即质心加上"事件落在帧内均匀位置"的平均采样年龄，`= N*Tf/2`。它是 sigma²·age 恒等式里的那个延迟量，与 tsettle 不混用。

三种测法都由 `make test` 固化，避免"延迟"一词在不同口径间偷换。

## 非白噪声（1/f 粉红，拐点 ~18 Hz）

同一组 N 实测：sigma 1.852 / 0.967 / 0.381 dB，`sigma²·age` 为 9.15 / 19.94 / 24.71 dB²·ms，远高于白噪声常数。因为 1/f 帧功率自带相关，`N` 帧不再是 `N` 个独立样本（等效独立帧数 1.00 / 3.67 / 23.69）。此时白噪声公式只给下界，真实换手更差；常数形式的失效本身就是过零点以下的低频相关性证据。

## 交叉验证

- 一阶指数平滑 `alpha=1/8`（同样 8 帧的记忆量）：age 40.00 ms、sigma 0.0989 dB、`sigma²·age` 0.3911 dB²·ms，与盒式的 0.393 一致 —— 交换常数不是盒式平均的副产品。
- 自检覆盖：`1/sqrt(N)` 律（三个 N，误差 <0.6%）、dB 刻度（对数正态 1.303 dB）、阶跃闭式解、群延迟。

## 用法

```
make test            # 自检
make bench           # 默认 50 ms / 0.15 dB
./meter bench 30 0.2 # 自定义 tsettle 预算与 sigma 目标
./meter sweep 6 7 11 # 指定帧数扫边界
./meter map          # 规格地图（预算 × 目标的可行 N 带）
```
