# 混叠残留上界、最小倍率与三档实测

实验代码：`src/aliasing_bound.c`（`make test` 自动运行，输出实测表并自检）。

## 1. 模型

- 输入采样率 `fs`，输出采样率 `r·fs`，`r = 1/D`（整数倍抽取）。**倍率 r 越高**：输出样本越多（越慢），但抗混叠滤波器的过渡带越宽（混叠越少）。
- 抗混叠滤波器：Kaiser 窗 sinc，阶数 `N = 128`。
  - 通带边 `ωp = 0.8π/D`（保留新奈奎斯特带的 80%）；
  - 阻带边 `ωs = π/D`（折叠频率）；
  - 过渡带宽 `Δω = ωs − ωp = 0.2π/D = (1−0.8)·π·r`。

## 2. 上界推导

**(a) 混叠只经过阻带。** 抽取 `D` 后，输出频率 `Ω` 处叠入所有满足 `Dω ≡ ±Ω (mod 2π)` 的输入分量。落入保留带 `Ω ∈ [0, D·ωp]` 的混叠只能来自输入频带

```
⋃_{k≥1} [ 2πk/D − ωp, 2πk/D + ωp ]
```

其最低边 `2π/D − ωp > π/D = ωs`（因为 `ωp < π/D`），即这些频带**全部位于阻带内**。

**(b) 阻带增益限幅。** 阻带内 `|H(e^{jω})| ≤ δs`，故单位幅度输入分量产生的混叠残留幅度 `ε ≤ δs`（宽带输入时残留能量同理以 `δs²` 乘以阻带能量为界）。

**(c) 由阶数到衰减。** Kaiser 经验阶数公式 `N ≈ (A − 8)/(2.285·Δω)`（`A = −20log10 δs`，单位 dB）反解得

```
A(N, D) = 2.285·N·Δω + 8 = 2.285·N·(1−0.8)·π/D + 8
```

**解析上界**：

```
ε(D) ≤ 10^(−A(N,D)/20) = 10^(−(2.285·N·0.2π/D + 8)/20)
```

`D` 越小（倍率 `r = 1/D` 越高）指数越大，残留越小；输出长度 `∝ r`，越慢。与"倍率越高混叠越少但越慢"一致。

## 3. 反解最小倍率

给定目标残留 `εt`，令 `A_req = −20log10(εt)`，解 `A(N, D) ≥ A_req`：

```
r_min = (A_req − 8) / (2.285·N·(1−0.8)·π)
```

代入 `N = 128`、`εt = 1e-3`（`A_req = 60 dB`）：

```
r_min = 52 / (2.285·128·0.2π) = 0.2830
```

可实现档位为 `r = 1/D`（`D` 整数），要求 `D ≤ 1/r_min = 3.53`，故**最小倍率档 `D0 = 3`（`r = 1/3 ≈ 0.333`）**。

## 4. 三档实测（D0−1、D0、D0+1）

每档设计对应 Kaiser 滤波器，扫描阻带找到 (i) 折入保留带的最坏频率、(ii) 全阻带峰值频率，分别用复指数单音实际"滤波+抽取"测量混叠残留（复单音避免实单音恰落在输出奈奎斯特点时的采样退化；非退化频率上实/复单音实测一致，程序内有自检）：

| D | r | A_pred (dB) | 上界 ε | 实测·折入保留带 | 实测·全阻带峰值 | 达成 A (dB) | 偏差 (dB) |
|---|---|------------|--------|----------------|----------------|------------|-----------|
| 2 | 0.5000 | 99.9 | 1.013e-05 | 3.217e-06 | 1.118e-05 | 99.0 | +0.85 |
| 3 | 0.3333 | 69.3 | 3.445e-04 | 1.252e-04 | 3.456e-04 | 69.2 | +0.03 |
| 4 | 0.2500 | 53.9 | 2.008e-03 | 7.335e-04 | 2.153e-03 | 53.3 | +0.61 |

结论：

- 上界随倍率单调：三档上界 `1.0e-5 < 3.4e-4 < 2.0e-3`，实测同序；
- 反解正确：`D=3` 上界 `3.4e-4 < 1e-3`，`D=4` 上界 `2.0e-3 > 1e-3`，`D=3` 确为满足目标的最小倍率档（保守准则下 `D=4` 全阻带峰值实测 `2.15e-3 > 1e-3`，同样不达标）；
- 折入保留带的实测残留三档全部低于上界。

## 5. 偏离解释（全阻带峰值实测略高于上界）

全阻带峰值实测在三档分别超出解析上界 `0.85 / 0.03 / 0.61 dB`。偏离来源是 **Kaiser 阶数公式本身是经验拟合**（对可达衰减的预测精度约 ±1 dB 量级），并非混叠机制或实现错误。两条定量验证（程序内自检）：

1. 三档"预测衰减 − 实测达成衰减"分别为 `+0.85 / +0.03 / +0.61 dB`，全部在 ±1.2 dB 以内，与经验公式的已知精度一致；
2. 阶数加 12% 余量（128 → 144）重新设计后，三档实测达成衰减全部 ≥ 原预测值——偏离被余量完全吸收，符合"公式系统性偏乐观约 1 dB"的解释。

此外，该峰值位于阻带边 `ωs` 的第一旁瓣，折叠后落在输出奈奎斯特点附近、在保留带 `[0, 0.8π]` 之外；就"保留带内残留"这一应用准则而言，三档实测全部低于上界（见表第 6 列），上界对保留带是保守的。
