# latency

按实测延迟做音画同步补偿。延迟不写死——写死的常数换设备就不同步，
所以每次用环回探测信号做互相关，实测当前设备/缓冲下的延迟，再按实测值补偿。

## 原理

1. **实测**：发出脉冲探测信号，环回采集，互相关取峰值 lag，得到延迟采样数。
   缓冲长度变了延迟就变，重新测即可，无需改常量。
2. **报错**：实测延迟为零（如采集无声、环回断开）时 `lc_init` 返回 -1，拒绝补偿。
3. **补偿**：事件调度时刻提前 `latency_samples` 个采样，每次补偿写一条记录。

## 四份材料（缺一视为未完成）

自测运行后全部可查：

| 材料 | 输出前缀 | 内容 |
|---|---|---|
| 同步误差表 | `sync_table` | 每个事件的计划/实际播放时刻与残余误差（ms） |
| 补偿记录 | `record` | 每次补偿的序号、实测延迟、缓冲长度、平移量 |
| 两种缓冲长度对照 | `buffer_compare` | 128 与 512 帧缓冲各自的实测延迟、平均/最大残余误差 |
| 与画面事件的偏差 | `visual_dev` | 每个画面帧事件，补偿前/后的音画偏差（ms） |

`materials_complete=1` 仅在四份材料都非空时成立。
