# latcal

双音频链（背景音乐 / 判定音）端到端延迟校准与补偿。`make test` 跑自检。

## 模型

每条链 = 块缓冲延迟 + 固定算法延迟，均用延迟线逐采样真实跑信号：

| 链 | 块延迟 | 固定 fx 延迟 |
|---|---|---|
| 背景音乐（双缓冲） | `2B` | 192 smp |
| 判定音（单块合成） | `B` | 32 smp |

真实延迟差 `Δ = B + 160`，随缓冲长度 `B` 增长，固定补偿量无法跨缓冲设置保持有效。

## 测量方法

- 可靠法：注入单位脉冲，输出端找峰值，带增益/纯度校验；重复 3 次取中位，
  散布超过 2 个采样判废。
- 有缺陷法（`probe_coarse`）：只能在块回调边界打时间戳，读数向上取整到整块。
  小缓冲误差可接受，大缓冲误差达数毫秒——校准后残差超过 1 ms 即暴露问题。

## 校准与 1 ms 红线

三个缓冲长度（64 / 256 / 1024）各测两条链，共 6 组延迟数据。补偿量覆盖写入
判定链的补偿延迟线（不累加）。每次补偿后重新实测两链到达时间差：

- 残差 `< 1 ms`：接受该测量；
- 残差 `>= 1 ms`：判定测量方法有问题，丢弃本次结果并用脉冲法重测，
  而不是在旧补偿上继续加量；重测仍超标则报错（`-4`）拒绝继续。

`comp_auto_smp` 在三个校准点之间线性插值，使补偿量随当前缓冲长度自动调整；
超出校准范围返回 `-1`，要求重新校准。
