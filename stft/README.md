# stft

分帧 STFT 的时间戳对齐建模与实测。`make test` 跑 C 自检并向
`../artifacts/` 写 CSV；`python3 tools/plot_alignment.py ../artifacts`
生成四张图和解析区间表。

## 1. 定义

采样率 `fs=48000`，帧 m 窗长 N、帧移 H，Hann 窗，覆盖样本 `[mH, mH+N)`：

- 帧起点时间戳 `t_start(m) = mH/fs`
- 帧中心时间戳 `t_c(m) = (mH + (N-1)/2)/fs`（Hann 能量对称中心，本模块用它）
- 超采样比 `ρ = N/H`（工程上取整数：1 临界、2 倍、4 倍超采样）

事件真实时刻 t 落在分数样本位置（未对齐全局采样网格），记相位
`u = (t·fs - mH - (N-1)/2)/H`。

## 2. 帧移与窗长对时间戳偏差的联合约束

偏差拆成两项独立的最坏值：

| 来源 | 量 | 含义 |
|---|---|---|
| 帧移网格量化 | `δ_g = H/(2fs)` | 事件在两个相邻帧中心之间，最近中心约定（A）的最大偏差 |
| 窗长涂抹 | `δ_w = N/(2fs)` | 事件可出现在窗内任意位置，首帧覆盖约定（B）用帧中心打戳的最大偏差 |

联合预算（两项独立最坏值相加）：

```
δ*(N,H) = δ_g + δ_w = (H + N)/(2·fs) ≤ Δ          Δ = 5 ms（验收门限）
```

即样本数约束 `H + N ≤ 2·fs·Δ = 480`。

## 3. 超采样下的松弛量

代入 H = N/ρ：

```
δ* = N/(2fs) · (1 + 1/ρ)
```

解出参数区间：

```
N ≤ 2·fs·Δ · ρ/(ρ+1)        H ≤ 2·fs·Δ/(ρ+1)
```

相对临界采样 ρ=1（此时窗预算只有 fs·Δ=240 样本=5 ms），窗长获得的
**松弛量**：

```
R(ρ) = N_max(ρ)/(2fs) - fs·Δ/fs = Δ·(ρ-1)/(ρ+1)
```

| ρ | N_max | H_max | R(ρ) |
|---|---|---|---|
| 1 | 240 样本 / 5.00 ms | 240 / 5.00 ms | 0 |
| 2 | 320 / 6.67 ms | 160 / 3.33 ms | 1.667 ms |
| 4 | 384 / 8.00 ms | 96 / 2.00 ms | 3.000 ms |
| ∞ | 480 / 10.00 ms | 0 | 5.000 ms（饱和，窗预算翻倍封顶） |

## 4. 设参

选 **N=256, H=128（ρ=2）**：δ*=4.000 ms ≤ 5 ms，留 1 ms 余量；
窗时长 5.33 ms 对低频事件足够，帧移 2.67 ms 时间分辨率可接受。

实测对照（`../artifacts/summary.csv`）：

| 配置 | 解析预算 | 实测 A 最坏 | 实测 B 最坏 | 判定 |
|---|---|---|---|---|
| N=256 H=128 ρ=2 | 4.000 | 1.323 | 2.656 | PASS |
| N=256 H=64  ρ=4 | 3.333 | 0.667 | 2.667 | PASS |
| N=128 H=64  ρ=2 | 2.000 | 0.667 | 1.333 | PASS |
| N=256 H=256 ρ=1 | 5.333 | 2.656 | 2.656 | FAIL |
| N=512 H=256 ρ=2 | 8.000 | 2.656 | 5.302 | FAIL |
| N=512 H=512 ρ=1 | 10.667 | 5.323 | 5.323 | FAIL |

实测值均落在对应解析项之内（扫描是离散分数位置，最大值只逼近不到达
H/2、N/2 理论界）。越界配置判 FAIL，不通过。

## 5. 两种打戳约定与平局

- A 最近中心帧：偏差有界 H/(2fs)，是 Hann 能量最大帧（实测校验）。
- B 首覆盖帧 + 中心戳：偏差有界 N/(2fs)，实现简单但偏差大。
- 事件恰在两帧正中（半帧移相位）时两帧 Hann 能量解析相等，代码以
  1e-12 相对容差识别平局并判给 A，避免浮点求和顺序造成的伪失配。
