## 增益斜坡核

斜坡形状由编译期开关 `MIXER_SMOOTH_RAMP` 选择：

| 值 | 核 | 行为 |
|---|---|---|
| `1`（默认） | 三次平滑阶跃 `s(x)=3x²−2x³` | 两端 C1 连续（`s′(0)=s′(1)=0`），`|s″|≤6`，消除斜坡收尾处的导数跳变 |
| `0` | 线性 `s(x)=x`（旧实现，含原 `t>1` 钳位） | 与改动前逐比特一致 |

关闭改动、回到旧行为：

```
make clean && make test RAMP_DEF=-DMIXER_SMOOTH_RAMP=0
```

平滑核的差分证据（一阶/二阶离散差分、解析核逐点对照、二阶导上界 6）
内置于自检；独立复现脚本与逐样本数据见 `../artifacts/ramp_analysis/`。
