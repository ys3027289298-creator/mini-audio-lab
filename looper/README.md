# looper

循环播放接缝（loop seam）的样本级处理与相位连续性证明，独立构建自测。

| 文件 | 内容 |
|---|---|
| `src/looper.c` | 周期裁剪、接缝钉值 cos² 交叉淡化、直通开关、接缝度量、循环差分 DFT 泄漏模型自检 |
| `THEORY.md` | 相位残差与接缝步长的区分、基频整周期条件推导、离散泄漏量估计、两种修复的连续性证明 |
| `tools/plot.py` | 读取自检输出的三份 CSV 生成 `seam_report.svg` 三联图，纯标准库无依赖 |

## 用法

```sh
make test   # 构建 + 自检（全部 check=1 才返回 0），生成 seam_*.csv
make plot   # 生成 seam_report.svg：接缝波形 / 循环一阶差分 / 频谱对照
make clean
```

## 自检覆盖的证明链

1. **整周期条件**：$q=24$ 的循环相位残差严格为 0、无谱泄漏；$q=23.5$（半 bin）
   残差理论值 $1-\cos(47\pi)=2$，落在二次界 $2\pi^2\varepsilon^2$ 与线性界
   $2\pi\varepsilon$ 内。
2. **泄漏模型**：循环一阶差分的 DFT 导数恒等式逐 bin 校验；接缝单样本能量
   相对内部样本占主导；半 bin 循环的宽带底噪比整周期循环高 $10^{27}$ 量级。
3. **修复对照**：周期裁剪（残差降到单样本界的 0.33%）与交叉淡化（C0 严格为零、
   远端零修正、内部样本不触碰、宽带底噪降约 8.7 倍）。
4. **关闭处理**：`enable=0` 输出与输入 `memcmp` 位一致。
