# 距离衰减统一: 证据摘要

## 统一配置

只有一组参数, 不再有远近两套切换:

- `ref = 1.00 m` (近场平台边界, `d <= ref` 时 `g = 1`)
- `rolloff = 1.00` (远场 `g = ref / (ref + rolloff*(d-ref))`; 取 1 时即 `ref/d`)
- `knee = 0.50 m` (C1 过渡段宽度)

旧模型 (对照): 近集 `rolloff = 0.20`, 远集 `rolloff = 1.00`, 按 `d = 3.00 m` 硬切换。注意: 仓库 HEAD 里只有一个公式、没有远近切换, 因此旧模型是按问题描述重建的对照基线, 参数为假设值; 统一曲线本身不依赖它。

## 曲线与 C1 证明

```
d <= ref              : g = 1
ref < d <= ref + knee : g = ref / (ref + rolloff * h(d-ref))
d > ref + knee        : g = ref / (ref + rolloff * (d-ref))
h(x) = x^2 * (2*knee - x) / knee^2,  0 <= x <= knee
```

`h(0)=0, h'(0)=0` -> 近场平台 `(g,g')=(1,0)` 与膝部在 `d=ref` 处值与斜率同时相等。

`h(knee)=knee, h'(knee)=1` -> 膝部与远场在 `d=ref+knee` 处值与斜率同时相等。

因此整条曲线在实数域上 C1 (二阶导在接缝处才跳变)。`h'(x) >= 0` 于 `[0,knee]`, 所以 `g` 全域单调不增。`make test` 中的 `seam_*` 项对单侧极限和浮点探测都做了检查。

实测接缝 (解析单侧极限):

| 接缝 | 值跳变 \|Δg\| | 斜率跳变 \|Δg'\| |
|---|---|---|
| ref = 1.00 | 0.000e+00 | 0.000e+00 |
| ref+knee = 1.50 | 0.000e+00 | 0.000e+00 |

浮点函数探测 (eps 缩小): 接缝处的值差按 O(eps) 或 O(eps^2) 趋于 0, 斜率差按 O(eps) 趋于 0, 即残余量随探测宽度消失, 不存在与 eps 无关的固定跳变 (斜率本身连续, 二阶导在接缝处才跳变, 所以斜率探测差是线性收敛):

| eps | seam_ref Δg | seam_ref Δg' | seam_knee Δg | seam_knee Δg' |
|---|---|---|---|---|
| 1e-03 | 3.994e-06 | 7.988e-03 | 8.898e-04 | 2.961e-03 |
| 1e-04 | 5.960e-08 | 8.000e-04 | 8.893e-05 | 2.963e-04 |
| 1e-05 | 0.000e+00 | 8.011e-05 | 8.881e-06 | 2.965e-05 |

## 四份材料

1. `distance_level.csv` — 距离-电平: 每 0.05 m 的旧模型/统一模型增益与 dB, 并给出画面预期的 `min(1, ref/d)`。
2. `first_diff.csv` — 一阶差分: 0.50..4.00 m 每 0.01 m 的相邻差, 在旧模型切换点可见 -6.62 dB 的差分尖峰。
3. `jump_counts.csv` — 突跳采样计数: 音频采样率、视频帧率与 1e-4 m 距离扫描三条序列, 在多个阈值下统计 |Δg| 超限的样本数。
4. `event_deviation.csv` — 与画面事件对齐后的偏差: 每帧一行, 事件包括出生、切换、最近点、最大偏差帧等; 偏差定义为与画面线索 `min(1, ref/d)` 的 dB 差。

`error_cases.csv` 为附加材料, 记录零距离等错误路径。

## 零距离

`dist == 0` (含 `-0.0`) 返回 `ATTEN_ERR_DIST_ZERO`, `dist < 0` 返回 `ATTEN_ERR_DIST_NEG`, NaN/inf 返回 `ATTEN_ERR_NONFINITE`; 所有错误路径都把 `out_gain` 写成 `0.0`, 绝不静默返回满电平。自检项:`zero_dist_err`, `zero_dist_not_full`, `neg_zero_dist_err`。详见 `error_cases.csv`。
