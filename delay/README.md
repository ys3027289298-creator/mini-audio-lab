# delay

互相关延迟估计与 Cramér-Rao 下界（CRLB）。

`make test` 跑自检并打印测量数据；`make csv` 把测量数据写到
`../artifacts/delay/measurements.txt`，供画图脚本使用。

## 模型

参考帧 `x[n]`（单位均方）与延迟帧 `y[n]`：

```
y[n] = a·x(n − τ) + w[n],   n = 0..N−1,  τ 为小数样本
```

在圆周互相关 `r[k] = Σ x[n]·y[n+k]` 上找峰，再用互相关谱把峰插值到样本的
1/32，得到分数延迟 `τ`。整数峰 `argmax r[k]` 只精确到半个样本——这正是要
消除的取整误差。

## 精度下界（CRLB）

把 `τ` 视为周期带限信号的连续参数，Fisher 信息为

```
J(τ) = a²·Σ x'(n)² / σ² = SNR · Σ x'(n)²
```

由 Parseval，`Σ x'(n)² = Σ_k (2πk/N)² |X[k]|²`，于是

```
CRLB(τ) = 1 / (SNR · N · ⟨W²⟩)                单位：样本²
⟨W²⟩    = Σ_k (2πk/N)² |X[k]|² / Σ_k |X[k]|²
SNR     = a²·mean(x²) / σ²
```

这是任意无偏估计量方差的下界；效率定义为 `CRLB / 实测方差`，理想值 1。
`⟨W²⟩` 衡量信号带宽：带宽越宽、频率成分越高，下界越低。

## 可测性判据

无延迟副本时，归一化峰值

```
z = √N · max_τ |r(τ)| / √(E_x·E_y)
```

近似是 `~2·B·N` 个标准正态滞后取最大值，集中在 `√(2 ln N)`（本例约 3.5）；
由 Cauchy-Schwarz 恒有 `z ≤ √N`。`z < Z_MIN = 6` 时峰值与噪声不可区分，报告
`measured = 0`、`crlb = NaN`，而不是给出一个看似精度的错数。

## 自检覆盖

- 互相关曲线（±3 样本，0.1 步长），可直接画图；
- 分数延迟 vs 整数取整：误差从 ~0.37 样本降到 ~0.001 样本；
- 两种信噪比（0 dB、10 dB、各 400 次）实测均方误差与 CRLB 比较，给出效率；
- CRLB 随 SNR 按 1/SNR 缩放（10 dB 差 → 方差 10 倍）;
- 低信噪比（−30 dB）全部判为不可测；±10/−20 dB 处判据正确分层；
- 输入校验（空指针、静音帧）。

## 实测结果（`make test` 打印）

帧长 N=512，占用带宽 0.35（单边）；实测 `⟨W²⟩ ≈ 1.75`（单位 1/样本²）。

| SNR | CRLB σ | 实测 RMSE | 效率 | 可测比例 |
|---|---|---|---|---|
| 20 dB | 0.0033 | 0.0035 | 0.93 | 100% |
| 10 dB | 0.0106 | 0.0107 | 0.97 | 100% |
| 0 dB | 0.0334 | 0.0329 | 1.03 | 100% |
| −5 dB | 0.0594 | 0.0624 | 0.91 | 100% |
| −10 dB | 0.1056 | 0.1060 | 0.99 | 85% |
| −12 dB | 0.1329 | 0.1192 | — | 34% |
| −15 dB | 0.1877 | — | — | 2% |
| −20 dB | 0.3338 | — | — | 0% |

- 整数取整的 RMSE 是 **0.370 样本**，分数估计把它降到 0.001 样本（单次、20 dB），
  0 dB 下蒙特卡洛 RMSE 为 0.033 样本——仍与 CRLB 相符。
- 效率在 −10 dB 以上稳定在 **0.90–1.06**：估计量基本达到下界（高于 1 的部分是蒙特卡洛
  涨落，不是超过了下界）。
- 半可测点约在 **−12 dB**；再低则 `z < 6`，`measured = 0`，不下结论。
  自检中 1500 次/点，没有出现"测出来但错到半个样本以外"的情况——判据宁可拒绝，
  也不输出错数。
