# room_reverb

局部材质加权混响实验。把房间表面按材质分区，用两种 Sabine 公式与镜像
声源（image-source）仿真对照，验证"全局一个混响时间常数"为什么解释不了
角落与吸音棉前的听感差异。

## 模型

房间 8 × 6 × 3 m，六个面分属三个材质分区（吸声系数按 125 Hz–4 kHz
六个倍频程频带给出）：

| 分区 | 面 | 面积 | 特征 |
|---|---|---|---|
| foam（吸音棉） | x=0 西墙 | 18 m² | 低频弱、1 kHz 以上强吸声 |
| wood（木板） | y 两面侧墙 | 48 m² | 中等吸声 |
| concrete（硬墙） | 东墙 + 地板 + 天花 | 114 m² | 全频近全反射 |

- `src/room.py`：房间几何、材质分区、声源（贴西墙 0.7 m）与三个接收点
  （中央、混凝土/木硬墙角、吸音棉墙前 0.3 m）。
- `src/sabine.py`：
  - 全局 Sabine `T60 = 0.161 V / Σ Sᵢαᵢ`（一个常数，基线）；
  - 局部 Sabine：分区吸声量先按 1/d 距离权重做二次加权
    （`rᵢ = (1/dᵢ) / mean(1/d)`，等距时严格退化为全局公式），
    支持按声源距离（题目要求，所有接收点共用一个值）和按接收点距离两种取法，
    并返回各分区对加权吸声量的占比，用于主导分区归因。
- `src/images.py`：矩形房间镜像声源枚举（每轴 30 阶，共 226 981 个），
  反射增益 `r = √(1-α)` 按命中墙面逐次相乘，含 1/d 几何扩散与解析 EDC。
- `src/render.py`：六个倍频程带的带限脉冲响应渲染（镜像脉冲 + 能量校准的
  指数衰减随机尾）、Schroeder 反向积分、T30 与 EDT 拟合。
- `src/experiment.py`：端到端实验，打印对照表、写 CSV 与四张图。
- `src/test_room.py`：物理自检（镜像位置、反射计数、直达时延、EDC 单调性、
  均匀权重退化等）。

## 运行

```
make test   # 自检
make run    # 完整实验，产物在 artifacts/
```

## 产物（artifacts/）

- `t60_comparison.csv`：每个接收点、每个频带的渲染 T30、EDT、解析 ISM T30、
  三种 Sabine 公式值与拟合 R²；
- `zone_shares.csv`：各接收点到分区的距离、距离权重与分区吸声占比；
- `fig1_geometry.png`：房间平面与材质/声源/接收点布局；
- `fig2_impulse_responses.png`：三个接收点的宽带脉冲响应；
- `fig3_schroeder_edc.png`：渲染 Schroeder 衰减曲线与解析镜像 EDC；
- `fig4_t60_comparison.png`：T30 与 EDT 的测量值/公式值逐频带对照。

## 主要结论

1. 全局 Sabine 中频 T60 = 1.04 s；声源距离加权局部公式 = 0.87 s，且对所有
   接收点是同一个常数——题目指出的缺陷在数值上复现。
2. 仿真测得的 T30 三个点都在 ~1.4 s 且随频带几乎不变：单面吸音棉的非扩散
   场里，高频先快速衰减，随后避开该墙的慢路径主导尾段。Sabine（含距离
   加权版）假设扩散场，高频严重低估 T60。
3. 位置差异主要体现在 EDT（早期衰减）和频谱平衡（E250/E2k），而非 T30；
   硬墙角最暗（+2.9 dB）。
4. 与公式差得最多的是吸音棉墙前接收点（解析 EDC 全频带平均 |Δ| ≈ 0.74 s），
   主导分区即 foam 本身——占该点距离加权中频吸声量的 91.5%。
