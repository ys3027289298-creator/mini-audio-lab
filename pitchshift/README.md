# pitchshift

`make test` 跑自检。也可以直接喂素材：`./pitchshift footstep.wav`
（单/多声道会混成单声道，支持 PCM16 与原位 float32）。

## 问题

整段按比例变速变调时，所有频率一起乘上比例，包括让脚步"有重量"的低频踏地声；
包络也按 1/ratio 缩短。快档之后低频变得尖细、失去重量，正是这两件事同时发生。

## 做法

把变调拆成两条路径，在**交叉频率**处接合：

- **低频路径**：交叉频率以下的原始素材，不挪音高、不改时长。踏地声的基频和包络都留在原地，
  所以"重量"和步长不随音高走。
- **高频路径**：交叉频率以上的素材，先按比例做 OLA 时间伸缩（音高不变、时长变），
  再按同比例重采样（音高变、时长回正）。净效果：音高按比例变，时长不变。
- **交叉频率**：原素材频谱能量重心（20 Hz–20 kHz，Hann 窗，零填充到 2 的幂），
  三档步速共用同一个值，**不**从处理后的素材重算。
- 两条路径用互补升余弦分频（低通 + 高通 = 1，−6 dB 点落在 fc），保证 `低 + 高` 精确重建输入；
  ratio = 1 时整条链是恒等。

整体缩放（`varispeed`）作为对照保留在同一份报告里。

## 三组九个数

`./pitchshift` 打印的 anchored 表，每档步速记「包络时长 ms、低频能量占比、交叉频率 Hz」：

```
speed   ratio    env_ms  low_share  crossover_hz
slow     1.00     241.6     0.7362          52.8
normal   1.25     231.6     0.7589          52.8
fast     1.50     222.4     0.7747          52.8
```

包络时长取 5 ms 单极点包络超过峰值 5% 的首尾跨度；低频能量占比取交叉频率以下能量占全带的比例。

## 交叉频率跟着音高飘的时候

报告末尾把最快一组的「挪动前后的交叉频率与能量占比」并列。整体缩放的对照行里：

```
                     crossover_hz   low_share
before (source)        52.8          0.7362
after anchored         52.8          0.7747
after naive            79.2          0.0000
```

naive 行的交叉频率是从处理后的素材重算的能量重心，随音高按比例上飘（52.8 × 1.5 ≈ 79.2），
低频能量占比掉到 0.0000。程序据此打印 `collapsed; crossover followed the pitch`。
双路径行把交叉频率钉在源素材的值上，占比没有塌。

## 自检

- 结构检查（任何输入都跑）：FFT 正确性、分频精确重建、ratio=1 恒等、锚定路径交叉频率固定且输出重心不漂。
- 素材检查（只对内置合成脚步声跑）：锚定路径包络保持、低频占比保持；整体缩放包络压缩、
  低频占比塌陷、重心漂到 1.5 倍。外部 WAV 因阈值依赖素材而跳过这些项，仍打印全部量测。
- 内置素材是确定性的合成脚步声（低频滑音踏地 + 中低频身体 + 高频噼啪 + 后跟摩擦），
  仓库里没有现成脚步声素材时的可复现参考；有真实素材时用参数入口跑同一套量测。
