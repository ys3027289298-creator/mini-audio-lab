# filter

四阶带通：巴特沃斯高通(fL) + 低通(fH) 双二阶级联。

平直度关系式：

- 单级二阶在 `Q_s > 1/√2` 时出现谐振峰：
  `G_peak(Q_s) = 2·Q_s² / sqrt(4·Q_s² − 1)`，`Q_s = 1/√2` 时恰为 1（最平）。
  低通峰位 `f0·sqrt(1 − 1/(2·Q_s²))`，高通峰位 `f0/sqrt(1 − 1/(2·Q_s²))`。
- 若把级 Q 直接设为带通 Q（原 bug），高 Q 时高通级在 fL 处谐振，
  通带低频端翘起。修正：级 Q 恒为 `1/√2`，带通 Q 只决定截止频率：
  `fL = fc·(sqrt(1+1/(4Q²)) − 1/(2Q))`，`fH = fc·(sqrt(1+1/(4Q²)) + 1/(2Q))`。
- 合成通带峰值（fc 处，含双线性频率畸变）：
  `G_pb(Q) = wH² / (wL² + wH²)`，`w = tan(π·f/fs)`。
