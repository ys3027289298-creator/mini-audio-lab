# 谱平均帧数设参：方差随帧数的下降律、低 SNR 偏离与设计公式

帧数不再靠猜。本文给出周期图功率平均的完整推导，用蒙特卡洛（`tools/spectral_mc.py`，
每点 2000–4000 次独立实现）验证理论曲线与实测曲线，量化低信噪比下的四类偏离，
并由抖动上限反解帧数；设参公式已在 `src/spectral.c` 的 `spectral_frames_needed()`
中落地，C 自检 14 项全过。

记号：帧长 N=64，周期 Hann 窗 w[n]=½(1−cos(2πn/N))，S1=∑w=N/2，S2=∑w²=3N/8。
周期图 P_k(b)=|FFT(w·x_k)[b]|²/S2，K 帧平均 P̄=(1/K)∑_k P_k。帧级 SNR 记 SN=10^(SNR_dB/10)，
输入噪声方差归一为 1，音调幅度 A=√(2·SN)。

---

## 1. 方差随帧数的下降律

### 1.1 单帧周期图的相对方差 C(ρ)

对在频点 b 上的音调，窗后复 DFT 系数 = 确定性信号分量 T 加圆对称复高斯噪声 Z。
该 bin 的局部信噪比

  ρ ≜ |T|²/E|Z|² = SN·S1²/(2S2) = **SN·N/3**（Hann，on-bin；实测 0 dB 时 ρ=21.5 vs 21.33）。

P=|T+Z|²/S2 服从非中心 χ²（2 自由度，非中心参数正比于 ρ），可直接算出

  **C(ρ) ≜ Var(P)/E[P]² = (1+2ρ)/(1+ρ)²。**

端点：纯噪声 ρ=0 → C=1（指数分布，CV=100%）；高 SNR ρ≫1 → C≈2/ρ，趋于 0。

### 1.2 独立帧的 1/K 律

K 个独立帧平均后方差降为 1/K，抖动（相对标准差，即 CV）

  **J(K) = √(C(ρ)/K)，即 Var(P̄)∝1/K。**

### 1.3 重叠帧：膨胀因子，先给保守常数，再给精确的 ρ 依赖律

50% 重叠时相邻帧共享一半样本，帧间相关。教科书（Carter/Carter-Nuttall 窗相关法）
取 Hann 50% 重叠膨胀因子常数 **IF=1.5**，于是保守设计律

  J = √(1.5·C(ρ)/K)。

但常数 1.5 是上界近似。本文用复高斯矩把它精确化。相邻帧在该 bin 的复 DFT
滞后相关（帧 1 用本地相位，共轭后逐样本相位抵消，结果与频点无关）：

  g ≜ |cov(X0[b], X1*[b])| / E|X[b]|² = (1/S2)∑_m w[m]w[m+N/2]。

Hann 下该窗段内积解析为 **g=1/6**（数值仿真 0.1667，全 bin 平坦，见图 3a）。
由 Isserlis 四阶矩：

| 周期图分量 | 滞后相关系数 |
|---|---|
| 噪声功率 \|Z\|² | g² = 1/36 |
| 交叉项 2Re(TZ*) | g = 1/6 |
| 信号功率 \|T\|²（确定音调） | 0（无波动） |

按 E[P]=1+ρ 中三项的方差权重合成，并对 K 帧的 (K−1) 个相邻对求和，得到**精确律**

  **IF(ρ) = 1 + 2(1−1/K)·(g² + 2ρg)/(1+2ρ)，g=1/6。**

两个渐近端点（K 大时）：

- ρ→0：IF→1+g² = **1.0278**（仿真噪声-only 拟合 1.057，差异来自有限 K 与采样误差）；
- ρ→∞：IF→1+2g = **4/3 = 1.333**（仿真饱和 1.323）。

即真实 IF 随 ρ 从 1.03 平滑升到 1.33，**教科书的 1.5 恒为安全上界**（实测最大 1.32 < 1.5）。
精确律在 K=32、6 个 SNR 上的最大误差 **3.7%**，而常数 1.5 律系统性过预测 8–12%（表 1、图 2）。

### 1.4 设计公式：由抖动上限反解帧数

给定抖动上限 J_max，保守取 IF=1.5（保证任何 ρ 下都达标）：

  **K_design = ⌈ 1.5·C(ρ) / J_max² ⌉，ρ=(N/3)·10^(SNR_dB/10)。**

这就是 `spectral_frames_needed(j_max, snr_db)`。15 组（3 个 J_max × 5 个 SNR）蒙特卡洛
复测，实测抖动全部低于预算（表 6，全 PASS，最小余量 +0.003）。

## 2. 低信噪比下的四类偏离（及在哪些频段被放大）

判据：**实测偏离超过对应解析预测即判不通过。** 下表每类都给出解析预测、实测值与结论。

### 2.1 重叠相关偏离（频段：全频段平坦，DC/Nyquist 特殊）

- 预测：内部 bin 滞后相关 γ=g²=1/36，与频点无关；30 个内部 bin 实测均值 0.0287（误差 3%）。
- DC(b=0) 与 Nyquist(b=N/2) 是实值、单自由度 bin，四阶矩结构不同，实测 γ 明显偏离 1/36
  （0.014 / 0.003），**不套用内部律，单独标记**；这两个 bin 的周期图方差本身也是内部 bin 的 2 倍。
- 结论：内部 bin 通过；边缘 bin 已知需单独处理。

### 2.2 离格音调的谱泄漏地板（频段：主瓣→近旁瓣→中远旁瓣依次衰减）

音调偏离整数 bin 半格（最坏情形 δ=0.5）时，Hann 旁瓣把能量泄到全频段。bin b 的泄漏局部功率

  ρ_leak(b) = (A²/4)·|W(2π(b−f_t)/N)|²/S2，

平均谱偏差 bias(b)=ρ_leak/(1+ρ_leak)。表 2（K=128）实测与解析最大差 0.0077，通过。
**频段放大顺序（偏离被放大的位置）：**

1. **主瓣（|Δb|≤1.5 bin）**：最先、最严重。0 dB 半格音在相邻 bin 偏差 38%，音调 bin 偏差 94%；
   随 SNR 每升 10 dB，ρ_leak 扩大 10 倍，主瓣偏差在 +5 dB 即饱和到 ~98%。
2. **主瓣边缘（Δb≈2）**：次一级，0 dB 偏差 38%，+10 dB 达 86%。
3. **近旁瓣（Δb 3–5 bin）**：0 dB 偏差 <1%，+10 dB 仍仅 ~1.4%。
4. **中远旁瓣（Δb≥6 bin）**：Hann −31 dB 旁瓣抑制使其在所有被测 SNR 下偏差 ≤0.3%，可忽略。

含义：泄漏地板不随 K 下降（是偏差不是方差），加帧无法消除，只能靠 on-bin 对准、
更好的窗或在主瓣/近旁瓣 bin 上做泄漏补偿。

### 2.3 有色噪声 AR(1) 的帧间相关（频段：低频被放大）

AR(1) 噪声 x[n]=φx[n−1]+ε[n] 把能量压到低频，PSD 随频点变化。表 3（K=64）逐 bin 测量：

- φ=0.5：内部 bin q≈1.00，无显著额外膨胀；
- φ=0.9：中频段 q≈1.00，但**低频段（b 1–4）q 升到 1.03**，边缘 bin b0 达 **1.48**（全表最大）。

放大机制：AR(1) 在低频的长相关时间使相邻帧共享的噪声样本更相关，g 在低频被抬高；
高频 bin 因 PSD 被白化而不受影响。注意同一频点噪声 PSD 本身下降会压低绝对 CV，
因此 q（相对白色同构律的比值）才是干净的膨胀指标。判据：内部 bin 偏离 <3% 通过；
强相关（φ=0.9）下的低频/DC 偏离超过白色律预测，**该工况判不通过，需在低频用有色律重设 K**。

### 2.4 非平稳地板（频段无关，但使 1/K 律整体失效）

块内噪声电平按 env(t)=1+d·sin(ωt) 调制。每帧期望功率随帧位置变化，产生与帧间随机
抖动正交的确定性地板。解析地板（各帧 env² 均值的跨帧 CV）与实测合成：

  J_total² ≈ J_1/K² + J_floor²。

d=50% 时地板 J_floor≈0.52（表 4）：K≤4 时随机项主导，K≥64 后地板主导，CV 在 ~0.025 处
停止随 K 下降（图 5a）。纯 1/K 律在 K≥128 的 q 达 1.09（超预测，判不通过）；
加入解析地板后 q 回到 0.94–1.07，模型恢复有效。该偏离与频点无关，是全谱性的帧数上限：
**超过地板对应帧数再平均不再降低抖动。**

### 2.5 幅度（Rice）平均 vs 功率平均（附带偏差—方差权衡）

若改平均幅度 √P 而非功率 P：高 SNR 下 Δ 方法给出 CV(√P)≈½CV(P)（表 5 实测比值 0.51–0.55），
看似方差减半；但低 SNR 下幅度服从 Rayleigh/Rice 分布，E[√P] 系统性偏低：
SNR=−15 dB 时幅度偏差 **−10.2%**，−6 dB 时 −3.8%。结论：功率平均无偏、应作为默认；
幅度平均仅在可校准该低 SNR 偏差时使用。

## 3. 设参、验证与判据汇总

### 3.1 设参步骤

1. 由工作点帧级 SNR 算局部 ρ=(N/3)·10^(SNR_dB/10)，再算 C(ρ)=(1+2ρ)/(1+ρ)²。
2. 由抖动上限 J_max 取 K=⌈1.5·C(ρ)/J_max²⌉（保守 IF=1.5，覆盖 ρ 全程，真实 IF≤1.33）。
3. 非平稳工况：校验 K 不超过地板帧数 K_floor≈(1.5C/ J_floor²)，超过则先治非平稳。
4. 强有色噪声（φ≥0.9）：在低频 bin 用有色 PSD 下的有效相关重算，或对低频单独加大 K。
5. 离格音调：主瓣/近旁瓣 bin 的泄漏偏差不靠 K 消除，需对准或补偿。

### 3.2 验证结论（全部数据在 artifacts/spectral_v4/）

| 项 | 解析预测 | 实测 | 判定 |
|---|---|---|---|
| 1/K 律，独立帧 | C(ρ)/K | 9 SNR×9 K 扫描 | 大 K 误差 <4%，通过 |
| 重叠 IF 常数（噪声） | 1.5（上界） | 1.057 | 实测低于上界，安全 |
| 精确 IF(ρ) 律 | 1.028→1.333 | 1.199→1.323 | 最大误差 3.7%，通过 |
| 内部 bin 滞后相关 | g²=1/36 | 0.0287 | 误差 3%，通过 |
| DC/Nyquist | 单自由度，单独 | 0.014/0.003 | 不套内部律，标记 |
| 泄漏偏差（4 频段×6 SNR） | ρ_leak/(1+ρ_leak) | — | 最大差 0.0077，通过 |
| 有色 φ=0.9 低频 | 白色律 q=1 | 低频 1.03，DC 1.48 | **超预测，不通过** |
| 非平稳 d=50%，K≥128 | 纯 1/K 律 | q=1.09 | **超预测，不通过**；加地板模型后通过 |
| 幅度平均低 SNR 偏差 | Rayleigh 偏差 | −10.2%@−15dB | 功率平均规避 |
| 15 组设参 | J≤J_max | 全组 margin>0 | 全 PASS |
