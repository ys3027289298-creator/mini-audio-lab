## 为什么换窗就失效

相干增益补偿 `Â = |X(k₀)| / W(0)` 只修正了窗的直流增益 `W(0)=Σw[n]`。
当单音频率不落在 bin 上（`f₀=(k₀+δ)/N`，`|δ|≤0.5`）时，峰值幅度还乘了一个
主瓣采样因子 `|W(2πδ/N)|`，它随窗形完全不同；且闭式补偿式本身是
Dirichlet 核的大 N 近似。两个误差来源都依赖窗系数，所以换窗即失效。

## 推导：两个量

余弦和窗 `w[n]=Σ_m a_m cos(2πmn/N)`（rect/hann/hamming/blackman 都是其特例）。

**式 1 — 幅度偏差关于窗长与频率：**

```
Δ(N,f) = g(δ) − 1,   δ = N·f − round(N·f)  （归一化 bin 偏移，|δ|≤0.5）
g(δ) = |Σ_m (a_m/2)(−1)^m [sinc(δ−m) + sinc(δ+m)]| / a₀
```

Hann 特例：`g(δ) = sin(πδ) / (πδ(1−δ²))`，bin 边界处 `g(0.5)=0.849`（−1.42 dB）；
rect：`g(δ)=sinc(δ)`，边界处 −3.92 dB。偏差只通过 `δ=N·f−round(N·f)` 依赖
窗长与频率，N 的残余影响由式 2 界定。补偿系数即 `c(δ)=1/g(δ)`
（Hann：`c(δ)=πδ(1−δ²)/sin(πδ)`）。

**式 2 — 式 1 在 bin 边界附近的误差上界：**

式 1 把 `sin(πδ)/(N sin(πδ/N))` 近似成 `sinc(δ)`。由 `sin x = x(1−u)`、
`u≤x²/6` 逐项估计，相对误差满足

```
ε(δ,N) ≤ π·(δ + Σ_{m≥1} m|a_m|/a₀) / (6 N² g(δ))
```

在 bin 边界 δ=0.5 处取最大值。rect 窗退化为 `π²/(24N²)`。
数值验证（δ∈[0,0.5] 全程，N=64…4096）：所有窗实测误差均在界内，
且 Hann/Blackman 因交叉项相消实测比界低 3 个数量级以上。

## 偏差曲线

`out/deviation_curve.png` / `out/deviation_curve.csv`：四种窗的
`20log10 g(δ)`（实线=精确 Dirichlet 值，圆点=FFT 实测，N=256，二者误差 <4e-15）。
换窗时边界处损耗从 −3.92 dB（rect）到 −1.42 dB（hann）不等——同一份
补偿系数换窗后偏差立刻超过千分之一，这就是必须按窗重推 `g(δ)` 的原因。

## 补偿残差

可用频段内对边界与内部频点（含最坏 δ=0.5）做实信号 FFT 验证，
全部窗 × N 的最大残差 **9.84e-4 < 1e-3**，判定完成。

## 失效频点（该式不成立的例子）

**Hann，N=1024，f₀ = 1.5 个 bin（48 kHz 下 70.3 Hz，k₀=1、δ=0.5）**：
补偿后残差实测 **2.86e-2**，超出阈值 28 倍。机制：负频率镜像泄漏
`g(2k₀+δ)/g(δ) = g(2.5)/g(0.5) = 0.0243/0.849 ≈ 2.9e-2`，与实测精确一致。
此时单窗 DFT 幅度不再只由 `g(δ)` 决定，式 1 失效——这正是可用频段表
把 hann 下沿划在 k₀=4 的原因。任何 k₀≤3 的频点（及 Nyquist 侧对称点）同样失效。
