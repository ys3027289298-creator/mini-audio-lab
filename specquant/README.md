# specquant

谱量化的位宽选择：先用谱熵估计素材的信息量下界，再把位宽、包体积、
重建误差放在一起比较，选出不超过下界两倍的位宽。

- 下界 `L = H_spec = -Σ p_k log2 p_k`（单边功率谱归一化为分布后的熵，
  bit/系数）；`K_eff = 2^H_spec` 为有效占用谱线数。另打印高斯熵率
  作更严的参考。
- 方案：单边 FFT 系数（n/2+1 个复数）共享一个峰值量程做 B bit
  均匀量化，包体积 = (n+2)·B + 16 bit。
- 对照：同位宽的时域均匀量化（同体积）。
- 规则：取满足 `B ≤ 2L` 的最大 B。

`make test` 跑自检，并对 n=1024 / n=8192 两档长度各出一张
位宽-体积-误差表。
