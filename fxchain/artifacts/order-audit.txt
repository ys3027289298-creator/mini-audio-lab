== 12. summary: which blocks break order invariance, and why ==
  X distortion: memoryless tanh.  Homogeneity error -26.9 dB, additivity -21.0 dB.
                It emits overtones that the next block then filters; no gain
                setting removes this.  It breaks order against every neighbor:
                R-X -18.8, D-X -24.4, C-X -19.9, X-F -24.0 dB (sections 6, 11).
  C chorus:     linear but time-varying (both linearity checks at the -200 dB
                floor), yet it fails to commute with every LTI block:
                R-C -11.4, D-C -14.0, C-F -62.5 dB.  This coupling is structural,
                not nonlinear: linearizing X does not touch it (section 11).
  R, D, F:      LTI.  Pairwise commutative at -120 dB or lower (sections 6, 7).
  Gain staging matched R/D/F levels, but it cannot linearize X or make C
  time-invariant, so it cannot produce a chain in which all 120 orders agree.
