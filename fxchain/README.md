# fxchain

五段串联效果链（混响 / 延迟 / 合唱 / 失真 / 滤波）与 5! = 120 种排列的顺序审计。

`make test` 跑自检，输出包含：

1. 每块在固定参考信号上的增益标定
2. 增益拉平后每个测试信号上的残余电平误差
3. 线性性分类（齐次性、可加性）
4. 逐样本内核 vs 分块渲染的一致性自检
5. 120 种排列对照基准顺序的偏差（dB）
6. 孤立两两对易子 K_AB 矩阵
7. 全链中交换一对的平均对易子
8. 落在容差内的排列，以及常规踏板顺序 X F C D R 的偏差
9. 消融实验：X 线性化 / C 冻结后，120 种排列的离散度
10. X 线性化后的两两对易子
11. 每对耦合中"由 X 的非线性造成"的份额
12. 结论摘要

距离度量：两条渲染先缩放到相同的窗内 RMS，再比较短时幅度谱，
所以剩下的是频谱/时域形状差，而不是总响度差。单位 dB = 10·log10(功率比)。
完全相同的渲染输出 -200 dB 底噪。

所有块都是固定状态机，合唱 LFO 相位在 sample 0 复位，测试信号在进程内生成，
因此每次运行结果可逐位复现。

## 结论（`./fxchain` 实测，见 `artifacts/order-audit.txt`）

- 基准顺序 R D C X F。120 种排列中只有 **2 种** 与基准的偏差在 -60 dB 以内：
  `RDCXF`（恒等，-200 dB）和 `DRCXF`（只交换 R/D，-119.7 dB）。
- 其余 118 种落在 -25.6 dB ~ -7.0 dB，全部超出任何合理容差。
- 不可交换的源头有两处，性质不同：
  - **X 失真**（无记忆 tanh）：对每一对相邻块都破坏顺序，
    R-X -18.8、D-X -24.4、C-X -19.9、X-F -24.0 dB。
    把 X 线性化后，这四对的对易子全部塌到 -120 dB 以下（第 10 节）。
  - **C 合唱**（线性但时变）：线性性检查全部在 -200 dB 底噪，
    却仍与每个 LTI 块不可交换：R-C -11.4、D-C -14.0、C-F -62.5 dB。
    这部分耦合与 X 无关，线性化 X 不会改变它（第 11 节）。
- R、D、F 三个 LTI 块两两可交换，对易子在 -120 dB 或更低。
- 增益/阻抗拉平只统一了 R/D/F 的电平（第 1、2 节），
  改变不了 X 的非线性，也改变不了 C 的时变性。所以"拉平增益即可任意重排"不成立。
- 第 9 节的控制条件：X 线性化 + C 冻结成固定抽头后，五块全为 LTI，
  120 种排列全部在 -115 dB 以内，顺序无关性成立。这证明问题确实只来自 X 与 C。

## 参数

| 块 | 实现 |
|---|---|
| reverb | 4 个并联阻尼反馈梳状（557/601/647/701）+ 3 个全通（113/89/71） |
| delay | 578 样本，反馈 0.45，环内二阶低通 |
| chorus | 两个分数延迟抽头，2.3 Hz / 0.37 Hz LFO，干湿 0.5 |
| distortion | 对称 tanh，drive 3.0 |
| filter | RBJ 二阶高通，fc 2 kHz，Q 0.707 |

混响和延迟的输入各有一个 DC 阻断器：梳状环在 DC 的环增益正好是 1.0。

## 文件

- `src/fxchain.c` — 五块实现、逐样本内核、120 排列审计、消融与归因
- `artifacts/order-audit.txt` — 一次完整运行的全部输出
