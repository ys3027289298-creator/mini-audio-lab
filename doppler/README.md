# doppler

运动声源掠过固定听者时的音高变化（多普勒）。`make test` 跑自检，`make report` 重新生成 `../artifacts/doppler/`。

## 1. 解析式

听者在原点，声源沿 x 轴按 `x(te) = x0 + v0·te + ½a·te²` 运动、距视线 `d`，发 `f0` 纯音，声速 `c`。
听者时间 `t` 收到的，是推迟时刻 `te` 发出的波前：

```
t = te + r(te)/c,        r(te) = √(x(te)² + d²)                      (1)
```

对 (1) 隐函数求导：`dt/dte = 1 + vᵣ/c`，其中径向速度 `vᵣ = x·v/r`（远离为正）。于是

```
f(t) = f0 · c / (c + vᵣ(te))                                          (2)
```

再对 (2) 求导，得到瞬时频率的变化率（chirp），也就是后面误差界的系数：

```
df/dt = −f0·c² · [ (v² − vᵣ²) + x·a ] / ( r·(c + vᵣ)³ )               (3)
```

实现 `src/doppler.c`：`doppler_at` 给出 `(te, x, v, r, vᵣ, f)`，`doppler_chirp` 给出 (3)。

两点容易写错：

- `vᵣ` 必须取**推迟时刻**的位置和速度。用当前时刻 `t` 的位置代入 (2)，掠过瞬间恰好 `vᵣ = 0`，
  峰值频移被抹平——正是"源头掠过、音高没变化"的症状。
- `vᵣ` 是沿视线的投影，不是速率。侧掠时 `vᵣ` 过零，音高在最近点回到 `f0`；整段恒为同一个偏移
  通常是把 `vᵣ/c` 当成了常数 `v/c`。

### 1.1 推迟时刻求解

- `a = 0`：把 (1) 平方得 `(c²−v0²)te² − 2(c²t + x0v0)te + (c²t² − x0² − d²) = 0`，取 `te < t`
  且残差最小的根。二次项系数在 `|v0| → c` 时趋零，代码按 `c²+ v0²` 归一化后判定，退化为线性方程，
  **不会除以零**。
- `a ≠ 0`：对 `g(τ) = τ + r(τ)/c − t` 做带符号区间保护的 Newton 迭代；`g' = 1 + vᵣ/c > 0`（亚声速），
  最近点附近 `g'` 很小，区间保护防止跳到另一支。

## 2. 与相位累积法逐样本对照

| 路径 | 相位 | 性质 |
|---|---|---|
| 解析 | `φ(t) = 2π·f0·te(t)` | 精确，但需要回溯几何 |
| 累积 | `φ[n] = φ[n−1] + 2π·f(t_n)/fs` | 可流式；用左矩形积分近似 (2) |

相位步进反推频率是**后向差分**：

```
f_back(t_n) = wrap(φ_n − φ_{n−1})·fs/(2π)
```

把 `f` 在一个采样间隔内视为常数，后向差分读到的是区间平均值，落在 `t_n − h/2`：

```
f_back(t_n) − f(t_n) = −(h/2)·df/dt + O(h²) = −(h/2)·chirp + O(h²)     (4)
```

中心差分用**两个单步**相加（先各自 wrap 再相加，避免两样点跨度先折叠）：

```
f_center = [wrap(φ_n − φ_{n−1}) + wrap(φ_{n−1} − φ_{n−2})]·fs/(4π)     (5)
```

(5) 误差为 `O(h²) ∝ 1/fs²`，(4) 为 `O(h) ∝ 1/fs`。自检逐条验证：

- `backward_bias_bounded`：两档采样率下实测 `|f_back − f| / ((h/2)·max|chirp|)` 落在 1 的 ≈1e−6 内；
- `center_error_second_order`：fs 48 k → 8 k 时 (5) 的误差放大 30–42 倍（6 倍采样间隔 → 36 倍）；
- `phase_error_scales_with_h`：8 k / 48 k 的后向误差比 ≈ 6。

## 3. 混叠边界

相位步进 `Δφ = 2π f/fs`，`|Δφ| ≥ π` 即 `f ≥ fs/2` 时相邻样本无法唯一还原。检测必须用**真实未折叠**的步进
`|φ_n − φ_{n−1}|`：折叠后的值本身看不出多绕了几圈（1.3π 折成 −0.7π 和普通样本无异）。命中即把该样本的
`f_back`/`f_center` 置 NAN，不参与误差统计；`alias.csv` 与 `table.csv` 的 `aliased_samples` 都按此判定。

临界径向速度（迎面时 `vᵣ = −|v|`）由 `f0·c/(c + vᵣ) = fs/2` 得

```
vᵣ,onset = c·(2·f0/fs − 1)        （负值 = 迎面需要接近声速）
```

| fs | 48000 | 8000 | 1000 | 880 |
|---|---:|---:|---:|---:|
| `vᵣ,onset` (m/s) | −336.712 | −305.270 | −41.160 | 0.000 |

880 Hz 下连静止音源（440 Hz）都正好落在 Nyquist 上，故 `onset = 0`：任何迎面接近都混叠。
实测（`alias.csv`，fs = 1 kHz 与 880 Hz）：

- fast / 1 kHz：499 个样本混叠，从 `t = −0.498 s` 到 `t = 0`；slow 同条件 0 个。
- 880 Hz：两档各 452 个混叠样本，覆盖 `−0.4977 … 0.0148 s`（slow 峰值 480.2 Hz > 440 Hz 也越界）。
- 边界帧与逐点判据 `f ≥ fs/2` 一致：3752 行中仅 2 行落在 ±0.2% 的 f 与步进近似差内
  （`f/nyquist = 0.9999` 而 `step/π = 1.0002`）：判据用的是未折叠真实步进，而 `f/nyquist` 由该步进反推，
  两者在 `f` 恰好擦过 Nyquist 时差一个样本的量化，属预期。

`alias.csv` 与 `alias.svg` 给出逐样本的 `phase_step_pi` 与 `f_over_nyquist`；fast 在 1 kHz 下越过 π 线的时间段
就是混叠段。

## 4. 两档速度耗时（`artifacts/doppler/timing.csv`）

`doppler_at` 每样本一次：48 kHz、1 s、重复 20 次，`-O2 -std=c11`：

| profile | µs/样本 | ns/样本 |
|---|---:|---:|
| slow（匀速，闭式二次） | 0.014 | 14.3 |
| fast（加速度，Newton） | 0.074 | 73.7 |

差 5 倍来自求解器：匀速走闭式二次求根，加速度走带区间保护的 Newton（实测平均 4.0 次、最多 5 次迭代）。
两档的算术量差异只来自 `a = 0` 分支，与速度大小无关。

## 5. 零速度与关闭

- **零速度不除零**：`v0 = 0, a = 0` 时 (1) 直接给 `te = t − r/c`，`vᵣ = 0`，`f = f0` 精确相等；
  二次求根对 `|v0| = c` 的退化情形也做了归一化判定。自检 `static_f_exact`、`zero_speed_ones`
  逐位（memcmp）验证输出全为 `1.0f`。
- **关闭行为不变**：`doppler_enable(m, 0)` 后 `doppler_ratio` 恒返回 `1.0`、`doppler_track` 全部写 `1.0f`，
  不进入几何求解；自检 `disabled_identity` 用 memcmp 比对全 1 缓冲。重新开启立即恢复。
- 机器学习/流式接线：`doppler_track` 把逐样本 `f/f0` 交给重采样器或移调器，关闭时比例为 1
  即旁路。
