# lowpass

4 阶 Butterworth 低通（两个双二阶级联，双线性变换 + 频率预畸）。扫描截止频率，
以两个互相冲突的目标做帕累托分析，并串联 `resampler` 的线性重采样实测。

## 两个目标（都取最小化）

| 目标 | 定义 |
|---|---|
| A 混叠残留 (dB) | 实测频率响应中，2:1 抽取会折回带内的阻带能量（250–500 Hz，归一到 DC 增益） |
| P 相位失真 (rad) | 信号带 0–125 Hz 内，解卷绕相位相对最佳拟合直线（纯延迟）的幅度加权 RMS 残差 |

截止频率调低 → 阻带抑制更深、A 更小，但带内群延迟起伏更大、P 更大，二者构成权衡。

## 用法

```
make test           # 构建并跑 C 自检，生成 sweep.csv / cascade.csv
python3 tools/verify.py    # 用 scipy 独立复核两个目标与帕累托标记
python3 tools/plot_results.py  # 生成 pareto_front.png / cascade.png
```

- `sweep.csv`：15 个截止频率候选（0.02–0.30 fs）的两目标值、群延迟展宽、帕累托标记。
  设计与响应测量用 double，运行时音频路径保留 float（与其他模块一致）。
- `cascade.csv`：无滤波基线 + 前沿上三个非支配点 P1/P2/P3，经低通后接 2:1 线性
  重采样（算法复制自 `../resampler/src/resampler.c`）的实测折叠比与通带增益。

## 结果摘要

- 15 个候选中 14 个在前沿上；fc=100 Hz 一点被 fc=80 Hz 支配（混叠更差且相位也更差），
  按要求保留为候选并在图中以灰色标出。
- 三个非支配点：P1 混叠最小（fc=20 Hz）、P2 折中（fc=180 Hz）、P3 相位最小（fc=300 Hz）。
- 串联实测：无滤波时折叠/通带能量比为 +1.25 dB；P2 在通带仅损 1.42 dB 的情况下把
  折叠压到 -40.1 dB，是实用甜点。P1 折叠 -34.7 dB 但通带也被压 40 dB。
- scipy 独立复核与 C 的差异：混叠 < 1e-4 dB，相位 < 5e-11 rad，帕累托标记零偏差。
