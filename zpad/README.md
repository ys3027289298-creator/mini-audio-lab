# zpad

补零插值误差衰减律标定 + 最小倍率推导 + 检测器接入。`make test` 跑全量自检（N=256，双音最坏相位/频偏扫描 + 5000 次随机检测试验）。

## 推导的两个量

**量 1 — 衰减率。** 补零倍率 R、双音间距 Δ（bin）下，抛物线插值对 DTFT 真实峰位（牛顿法精化）的误差满足

```
eps(R, Δ) ≈ C0 · Δ^(-m) · R^(-k)
```

实测拟合（12 相位 × 3 频偏取 max）：**k ≈ 3.04**（sinc 峰上抛物线插值呈立方衰减），**m ≈ 1.00**（常数随间距反比增长），C0 ≈ 29.5，残差比 ρ ≈ 1.02。

**量 2 — 最小倍率。** 目标 eps ≤ 0.01 bin、设计最小间距 Δ_min = 4 bin，含 1.25 余量：

```
R_min = min{ 2^j : C_use · R^(-k) ≤ 0.01 } = 16
```

检测器以 R = R_min = 16 补零。

## 阈值推导（不拍脑袋）

矩形窗 Dirichlet 核给出：≥2 bin 外最大副瓣 s_side = 0.1284（数值扫描），镜像裙边 s_img = 1/(π(2f_min−2))，近邻主瓣裙边 s_nb = 1/(π(Δ_min−d_bias))，峰位偏移界 d_bias = (3/π²)(A_max/A_min)/Δ_min + eps_target。

- 虚警上界 B_rej = 2(s_side + s_img)·A_max = 0.278（N/2 单位，双副瓣巧合）
- 真峰下界 B_acc = A_min − A_max·s_nb − A_min·s_img = 0.412
- 阈值 T = √(B_rej·B_acc)·N/2 = 0.338·N/2，两侧各约 20% 余量

检测流程：R_min 倍补零 → 迭代取最大 → 主峰半宽 ±2 bin 抑制 → T 截断。

## 交付指标（本次运行）

- **误判计数**：5000 次随机试验（单音/双音/静音，幅度 0.5–1.0，间距 4–40 bin）→ **0**；最大频率误差 0.111 bin，全部在推导界内（越界 0）。
- **两档耗时**（检测全流程，2000 次平均）：R=16 → 59.5 µs/frame；R=64 → 312.4 µs/frame（×5.25，符合 M·logM）。
- **衰减率失效反例**：Δ = 0.75 bin（< 主瓣零-零宽 2 bin）时两峰合并，误差钉死在 ≈1.04 bin 不随 R 衰减（律外推已降至 1e-4），检测器报 1 个音（真实 2 个）。衰减律适用下界即间距指标 Δ ≥ Δ_min = 4 bin。
