# peakpick

窗型 × 窗长组合选择的定量分析：解决「旁瓣被当主峰（误检）」和「两个相邻主峰
叠加成一个（漏检）」两类峰值检测错误。全部结论由确定性、可复现的试验给出，
C 与 Python 两套独立实现交叉校验，**最终推荐组合在试验网格内零误检、零漏检**。

## 1. 问题与判定口径

信号：fs = 48000 Hz，两个等幅正弦，频率 f0、f1 = f0 + Δf。分析段加长度 L 的
窗，4 倍零填充 FFT 后在幅值谱上取峰。

峰值检测器（C/Python 同规格）：

- 严格局部极大，且幅值 ≥ 全谱最大值 − 40 dB（报告门限，可在门限敏感度表中改）；
- ROI：两个真实音左右各 8 个分析窗 bin；
- 配对容差 ±0.5 bin。报告峰落在真值 0.5 bin 内算命中，否则记 **误检 FP**；
  真值 0.5 bin 内没有报告峰记 **漏检 FN**。
- 两音叠加成一个局部极大时只剩 1 个报告峰 → 必然 1 个 FN。

每个 (窗, L, Δf) 单元跑 16 个试验：8 个分数 bin 偏移（0 到 7/8 bin）× 2 个
两音相位（0、π/2），覆盖最差对齐情况。**单元 clean ⇔ 16 个试验 FP、FN 全为 0。**

## 2. 两类错误的物理来源（理论）

`tools/theory_study.py` 用 2^22 点零填充逼近连续窗谱：

| 窗 | 主瓣第一零点宽 (bin) | 临界间距 c (bin) | 最高旁瓣 (dB) |
|---|---|---|---|
| rect | 2.00 | 1.324 | −13.3 |
| hann | 4.00 | 1.885 | −31.5 |
| hamming | 4.00 | 1.670 | −42.7 |
| blackman | 6.00 | 2.068 | −58.1 |

- **漏检（主峰合并）**：两等幅窗谱 `g(u)+g(u−d)` 在中点的凹陷随间距缩小而消失，
  临界条件是中点经过 `g''` 的第一个拐点。临界归一化间距 c 只由窗型决定，
  因此临界窗长满足尺度律 **Lcrit = c·fs/Δf**。
- **误检（旁瓣当主峰）**：窗谱旁瓣高于报告门限就会产生假峰。rect 旁瓣 −13.3 dB，
  在 −40 dB 门下必然大量误检；hann −31.5 dB 同样越界；hamming/blackman 旁瓣在
  门限以下，单音不误检，但双音旁瓣叠加可能重新抬过门限。

## 3. 临界窗长与移动率

实测临界分两层（二分整数窗长，`results/lcrit.csv`）：

- **Lcrit_res（分辨临界）**：16 试验零漏检，误检不约束。实测系数 ĉ 与理论 c：

  | 窗 | 理论 c | 实测 ĉ_res | 偏差 |
  |---|---|---|---|
  | rect | 1.324 | 0.904* | — |
  | hann | 1.885 | 1.826 | −3.1% |
  | hamming | 1.670 | 1.554 | −7.0% |
  | blackman | 2.068 | 2.140 | +3.5% |

  \* rect 受「d_bin ≥ 1 才可分」的硬下限截断（见 §5），ĉ 不具物理意义，
  仅作网格拟合值保留。
- **Lcrit_full（严格临界）**：零误检且零漏检。rect、hann 在整个网格
  （L ≤ 8192）内不存在；hamming 仅 Δf ≥ 110 Hz 存在，等效 ĉ_full = 21.6 bin
  （双音旁瓣叠加把门槛从 1.67 抬到 21.6）；blackman 全间距可行，
  ĉ_full = 2.140，与分辨临界重合——旁瓣从不越界。

**移动率**：由尺度律 Lcrit = ĉ·fs/Δf 求导

```
dLcrit/dΔf = −ĉ·fs/Δf²        （负号：间距越大所需窗越短）
```

例（blackman，res）：Δf=50 Hz 时 −41.1 样本/Hz，100 Hz 时 −10.3，200 Hz 时
−2.57，400 Hz 时 −0.64。`fig3` 同时给出整数窗长的原始差分，量化台阶围绕
尺度律曲线上下 ±10–20%，间距越小移动率越大（小间距区窗长设计对间距误差最敏感）。

## 4. 组合可行域与最终选型

可行域见 `figures/fig1_feasible_region.png`（4 窗 × 9 窗长 × 37 间距三态图）：

- **rect / hann：−40 dB 门下全域不可行**，任何窗长都有旁瓣误检；
- **hamming：仅右上角可行**（大间距 + 大窗长，Δf ≥ 110 Hz 且 L ≥ Lcrit_full）；
- **blackman：可行域最大**，L ≥ 2.14·fs/Δf 即 clean。

**推荐组合：blackman 窗 + L ≥ ⌈2.14·fs/Δf_min⌉**（Δf_min 是预期最小双音间距）。
本网格实测：Δf_min=40 Hz 需 L ≥ 2563，Δf_min=50 Hz 需 L ≥ 2050，Δf_min=100 Hz
需 L ≥ 1025（取 2 的幂时向上取整，如 4096/2048/1024，并预留余量）。若能接受
更窄主瓣且保证 Δf ≥ 110 Hz，hamming 是次选，代价是 Lcrit_full 约为 blackman
的 10 倍（Δf=110 Hz 时需 8066）。

门限放宽时结论会变（`results/gate_sensitivity.csv`，单音 L=512 假峰数）：

| 门限 | rect | hann | hamming | blackman |
|---|---|---|---|---|
| −20 dB | 5 | 0 | 0 | 0 |
| −30 dB | 12 | 0 | 0 | 0 |
| −40 dB | 14 | 2 | 0 | 0 |
| −50 dB | 14 | 6 | 11 | 0 |
| −60 dB | 14 | 10 | 13 | 4 |

门限越浅（−20 dB）越不容易误检但弱信号会漏报；越深（−60 dB）blackman 也开始
误检。−40 dB 是 blackman 唯一在全门限扫描中保持 0 误检到 −50 dB 的窗。

## 5. 可行域外的实测反例（均可复现）

`figures/fig5_counterexample.png`，C 自测同参数：

- **反例 A（误检）**：rect，L=512，单音 3000 Hz。最高旁瓣 −13.3 dB 远高于
  −40 dB 门限，ROI 内报告 15 个峰，其中 **14 个误检、0 个真实对应**。
  证明 rect 落在可行域外，且与窗长无关（旁瓣电平不随 L 下降）。
- **反例 B（漏检）**：blackman，L=256，Δf=300 Hz（=1.60 bin < 2.14 临界）。
  两个真实音的主瓣叠加成 **1 个**局部极大（位于 3140 Hz），漏检 1；
  同窗长 Δf=400 Hz（2.13 bin）才分成 2 个峰。证明窗长不足时落在可行域外。

## 6. 验收口径与零错误证据

- 全网格 1332 个单元 × 16 试验 = 21312 次试验；不可行单元 1131 个，
  累计 FP=142134、FN=9096（`fig4`，均集中在可行域外）。
- **可行域内（推荐组合所属的 clean 单元）FP=0、FN=0**，由 sweep 的单调断言
  与全表计数共同保证；`make test` 与 `crosscheck.py` 全绿才算完成。
- 单调性：clean 谓词随 L 全局 False\*→True\*（148 条 (窗,Δf) 序列零违例）；
  zero_fn 在 d_bin ≥ 1 的物理可分上分支零违例。d_bin < 1 时宽主瓣窗可能在
  亚 bin 间距仍撑出两个局部极大（主瓣宽度 > 间距），该区域不具「两音可分」
  语义，res 临界只在上分支求解。

## 7. 复现方式

```
make test                       # C 自测（8 项 check + raw 计数）
python3 -I tools/theory_study.py    # 窗谱理论参数
python3 -I tools/sweep.py           # 全网格扫描 + 临界窗长/移动率（约几分钟）
python3 -I tools/crosscheck.py      # C/Python 原始计数逐项比对
python3 -I tools/make_figures.py    # 生成 figures/ 下 5 张 PNG+SVG
```

注：脚本以 `python3 -I` 运行（隔离 cwd，防同名模块投毒），并在脚本内显式补入
用户 site-packages 路径。
